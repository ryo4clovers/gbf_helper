# GBF Network Recorder

グランブルーファンタジー(`game.granbluefantasy.jp`)のプレイ中に発生するネットワーク通信(XHR/Fetchのレスポンス、画像、スクリプト)を、ブラウザの開発者ツールのNetworkタブと同じ仕組みで**受動的に**記録しておくためのChrome拡張機能です。

## 設計方針(重要)

この拡張機能は **Chrome DevTools Protocol(`chrome.debugger` API)でタブにアタッチし、Chromeが既に受信したレスポンスを横から読み取るだけ** です。拡張機能自身が`game.granbluefantasy.jp`宛てに何らかのリクエストを発行することは一切ありません。記録されるのは、あくまでユーザー自身の画面操作(クリック・遷移)によって**ゲーム自身のJSが発行した**通信の結果です。DevToolsのNetworkタブを開いて記録しているのと技術的には同じことをしているだけ、という位置づけです。

記録を開始すると、Chromeの仕様により画面上部に「(拡張機能名)がこのブラウザをデバッグしています」という表示が出ます。これは仕様上避けられない(かつ意図された)ものです。何かが裏で動いていることの可視化として捉えてください。

## インストール方法(開発者モードで読み込み)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ(`tools/network-recorder`)を選択

## 使い方

1. グラブルのタブ(`game.granbluefantasy.jp`)をアクティブにする
2. 拡張機能アイコンをクリックしてポップアップを開き、「記録開始」を押す
3. 画面上部にデバッグ中の表示が出るので確認する
4. 通常通りゲームをプレイ・画面遷移する(ジョブ画面を見る、キャラを見る、など)
5. 記録を止めたい時はポップアップの「記録停止」を押す
6. ポップアップの「記録内容を見る / エクスポート」から一覧・検索・エクスポートができる

エクスポートすると `gbf-network-recorder-export-{timestamp}.json` というファイルがダウンロードされます。このファイルをClaudeに渡せば、まとめて解析できます。

### 個別コピー / 個別エクスポート(v0.2.0〜)

一覧の行をクリックして詳細を開くと、「コピー」「この項目をエクスポート」の2つのボタンが使えます。

- **コピー**: JSON/テキストのレスポンスは整形してクリップボードにテキストとしてコピーします。画像はPNGとしてクリップボードにコピーします(貼り付け対応アプリならそのまま貼り付け可能)。全件エクスポートより手軽にClaudeへの共有(チャットに直接貼り付け)ができます。
- **この項目をエクスポート**: そのレコード1件だけを、元の形式(JSON/HTML/PNG等)のファイルとして単体でダウンロードします。ファイル名はURLの末尾から自動生成されます。

## データの保存先と内容

- 保存先はブラウザのIndexedDB(拡張機能のローカルストレージ)。サーバーには一切送信されません。
- `assets`(画像/JS/CSS): URLをキーに保存(同じURLへの再アクセスは上書きなので重複しない)
- `apiCalls`(XHR/Fetch/ドキュメント): 発生の都度、新規レコードとして保存(同じURLでも中身が変わりうるため)
- 画像はbase64エンコードして保存(バイナリも保持)

## 制約・注意点

- `chrome.debugger`は1タブにつき1クライアントしかアタッチできないため、DevToolsを別途開いている状態では記録を開始できません。
- サービスワーカー(background.js)がアイドルで一時停止しても、`chrome.debugger`のイベントリスナーは再度起動して受信を継続します(Manifest V3のイベント駆動の仕組み)。
- 記録対象ドメインは`game.granbluefantasy.jp`と`*.akamaized.net`(ゲームのアセットCDN)のみに絞っています。それ以外(広告・分析タグ等)は記録しません。
- v0.1.0時点でアイコン画像は未設定(Chromeのデフォルトアイコンで表示されます)。
- 画像コピーはPNG以外(JPEG等)の場合、内部でPNGに変換してからクリップボードに書き込みます(Clipboard APIがPNG以外を安定してサポートしないため)。
