# ゼウス(Zeus)

## 概要

光属性のSSR召喚石。オプティマスシリーズ（神石）。

| --- | --- |
| レアリティ | SSR |

| 入手方法 | ガチャ排出/ |

| レベル | HP | ATK |
| --- | --- | --- |
| Lv100(3★) | 790 | 2220 |
| Lv150(4★・最終上限解放) | 1120 | 3145 |

## 召喚効果

- 効果: 敵全体に光属性ダメージ(特大) / 味方にバリア効果を付与 / (4凸)敵全体に光属性3倍ダメージ / 味方にバリア効果(耐久3000/永続)を付与
- 出典: GameWith

## 加護効果(メイン編成時)

| 段階 | 通常スキル加護 | メイン装備時だけの光属性攻撃UP |
| --- | ---: | ---: |
| 0〜2凸 | 80% | なし |
| 3凸 | 120% | なし |
| 4凸 | 140% | なし |
| 5凸・超越Lv230未満 | 150% | なし |
| 超越Lv230〜239 | 160% | なし |
| 超越Lv240〜249 | 160% | 30% |
| 超越Lv250 | 170% | 30% |

- 通常スキルの対象系列は光・雷電・天光。メイン・サポートに適用し、メイン限定の属性攻撃30%はサポートに適用しない。
- 出典: 0〜4凸は既存GameWith記録、5凸・超越は[GameWith神石超越一覧](https://xn--bck3aza1a2if6kra4ee0hf.gamewith.jp/article/show/431318)（2026-10-05参照）。Lv250の効果文は下記実機詳細で確認。中間段階の数値・枠は要検証。

## サブ加護効果(サブ編成時)

| 段階 | 光属性キャラの光属性攻撃UP | 光属性キャラのHP UP |
| --- | ---: | ---: |
| 5凸以下・超越Lv210未満 | なし | なし |
| 超越Lv210〜249 | 10% | 10% |
| 超越Lv250 | 20% | 20% |

- 通常サブ枠・サブ加護専用枠で適用し、メイン/サポートからサブ効果を適用しない。通常スキル加護はサブ配置では発動しない。
- 2026-10-05に計算機へ段階別接続。同一神石を複数装備した属性攻撃・HPは最大値とし、属性攻撃はメイン30%とサブ10/20%の間でも最大値とする下書きモデル。重複配置の実測は未確認。
- Lv250の表示値は実機所持詳細で確認済み。中間Lvと他系統のHP加護との共存・丸めは未検証。計算モデルは下書きを維持する。

## 実機所持データ確認

- 確認日: 2026-09-09
- 確認段階: Lv250 / 6凸
- 表示ステータス: HP 1450 / ATK 4071
- 召喚効果: 敵全体に光属性12倍ダメージ/味方全体にバリア効果/高揚効果
- 加護効果: スキル「光」「雷電」「天光」の効果が170%UP / ◆メイン召喚石に装備時、光属性攻撃力が30%UP
- サブ加護効果: 光属性キャラの光属性攻撃力が20%UP/HP20%UP
- 出典: ユーザー提供のゲーム内所持召喚石詳細レスポンス
