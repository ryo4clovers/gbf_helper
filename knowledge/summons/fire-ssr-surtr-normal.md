## 召喚効果

### 初期『炎の剣』

- 効果: 敵全体に火属性5倍ダメージ(上限約63万) / 火属性キャラに / ・業火の刻印(最大5/消去不可) / ・火属性攻撃25%UP×3ターン / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 3凸

- 効果: 敵全体に火属性7倍ダメージ(上限約63万) / 火属性キャラに / ・業火の刻印(最大5/消去不可) / ・火属性攻撃50%UP×3ターン / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸

- 効果: 敵全体に火属性9倍ダメージ(上限約70万) / 敵に暗闇効果×3ターン / 火属性キャラに / ・業火の刻印(最大5/消去不可) / ・火属性攻撃60%UP×3ターン / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

## 加護効果(メイン編成時)

- 効果: 火属性攻撃力が50%UP / (3凸)火属性攻撃力が80%UP / (4凸)火属性攻撃力100%UP / バトル開始時に味方全体に業火の刻印を付与 / サブ加護:最大35%UP
- 出典: GameWith

## サブ加護効果(サブ編成時)

- 効果: 火属性キャラがそれぞれの業火の刻印の数に応じて火属性攻撃力UP(最大15%) / (3凸)火属性キャラがそれぞれの業火の刻印の数に応じて火属性攻撃力UP(最大25%)
- 出典: GameWith
