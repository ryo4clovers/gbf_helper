## 召喚効果

### 初期『ウブシュウキンナ』

- 効果: 敵全体に風属性5倍ダメージ(上限約63万) / 風属性キャラに狂風の刻印を付与(最大5/消去不可) / 3ターンの間、風属性攻撃25%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 3凸

- 効果: 敵全体に風属性7倍ダメージ(上限約63万) / 風属性キャラに狂風の刻印を付与(最大5/消去不可) / 3ターンの間、風属性攻撃50%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸

- 効果: 敵全体に風属性9倍ダメージ(上限約70万) / 風属性キャラに狂風の刻印を付与(最大5/消去不可) / 3ターンの間、風属性攻撃60%UP / 味方全体の回避率UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

## 加護効果(メイン編成時)

- 効果: 風属性攻撃力が50%UP / (3凸)風属性攻撃力が80%UP / (4凸)風属性攻撃力が100%UP / バトル開始時に味方全体に狂風の刻印を付与
- 出典: GameWith

## サブ加護効果(サブ編成時)

- 効果: 風属性キャラがそれぞれの狂風の刻印の数に応じて風属性攻撃力UP / (3凸)風属性キャラがそれぞれの狂風の刻印の数に応じて風属性攻撃力UP / (4凸)風属性キャラがそれぞれの狂風の刻印の数に応じて風属性攻撃力UP(最大35%)
- 出典: GameWith
