## 運用ルール

- ファイル名(および frontmatter の `id`)は次の形式に統一する:
  `{属性}-{レアリティ}-{英語名}-{バージョン}.md`
  - 属性: `light` / `fire` / `water` / `earth` / `wind` / `dark` / `none`(無属性、全属性対応の召喚石の場合。英語表記、小文字)
  - レアリティ: `ssr` / `sr` / `r`(小文字)
  - 英語名: 召喚石の英語名をkebab-caseにしたもの
  - バージョン: バージョン差分がある場合は英語kebab-caseで表す(例: `evolution`)。バージョン差分がない恒常召喚石は `normal` を使う。
  - 例: `light-ssr-lucifer-normal.md`(ルシフェル/SSR/光属性)
- 各ファイルは `_template.md` の形式(YAML frontmatter + ステータス/召喚効果/加護効果セクション)に沿う。ダメージ計算に関わる項目(ステータス、召喚効果、加護効果〈メイン編成時〉、サブ加護効果〈サブ編成時〉)を優先して記載する。召喚効果は上限解放段階(初期/3凸/4凸等)ごとに効果・初回召喚ターン・使用間隔・再召喚可否が変わることが多いため、段階ごとに`###`見出しを分けて記載する。
- 数値や効果は、公式発表や検証済みの一次情報を元に記載し、`source` に出典URLと取得日を明記する。Wiki等の二次情報のみの場合は `status: 下書き` とし、未確認事項は「未確認・要検証事項」に明記する。
- この一覧表は手動更新(MCPサーバーは `*.md` を直接スキャンするため、一覧の鮮度には依存しない)。
- 情報源や取得方法の詳細は [docs/data-collection-notes.md](../../docs/data-collection-notes.md) を参照。
