## 召喚効果

### 初期『ン･ガイ』

- 効果: 敵全体に闇属性5倍ダメージ(上限約63万) / 闇キャラに幽闇の刻印を付与(最大5/消去不可) / 3ターンの間、味方全体に闇属性攻撃25%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 3凸『ン･ガイ』

- 効果: 敵全体に闇属性7倍ダメージ(上限約63万) / 闇キャラに幽闇の刻印を付与(最大5/消去不可) / 3ターンの間、味方全体に闇属性攻撃50%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸『ン･ガイ』

- 効果: 敵全体に闇属性9倍ダメージ(上限約70万) / 敵全体に180秒の間、腐敗効果 / 闇キャラに幽闇の刻印を付与(最大5/消去不可) / 3ターンの間、味方全体に闇属性攻撃60%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

## 加護効果(メイン編成時)

- 効果: 闇属性攻撃50%UP / サブ加護:闇属性キャラがそれぞれの極闇の刻印の数に応じて闇属性攻撃力UP / (3凸)闇攻撃力が80%UPに強化 / サブ加護の強化上限が強化 / (4凸)闇属性攻撃力100%UP / バトル開始時に味方全体に幽闇の刻印を付与 / サブ加護:最大35%UP
- 出典: GameWith
