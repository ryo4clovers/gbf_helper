## 召喚効果

### 初期『パラダイス･ロスト』

- 効果: 敵全体に光属性ダメージ(特大) / 味方全体に攻撃力20%UP(攻刃加算)×4ターン
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸『パラダイス・ロスト』

- 効果: 敵全体に光属性ダメージ(特大) / 味方全体に / ・攻撃力30%UP(攻刃加算)×4ターン / ・HP30%回復(最大3000)
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 5凸『パラダイス・ロスト』

- 効果: 敵全体に光属性ダメージ(特大) / 味方全体に / ・攻撃力30%UP(攻刃加算)×4ターン / ・HP30%回復(最大3000) / ・活性効果×4ターン / └HP10%回復(最大500)/HP回復しない時ゲージ10%UP
- 使用間隔: 8ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 限界超越後Lv250『パラダイス・ロスト』

- 効果: 敵全体に自属性20倍ダメージ(上限約243万) / 味方全体に / ・HP回復(最大4000) / ・ディスペルガード効果×2ターン / ・純白の翼効果(消去不可)×4ターン / └攻撃力30%UP(攻刃加算) / └HP回復(最大1500)/回復しない時ゲージ10%UP
- 使用間隔: 6ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)
