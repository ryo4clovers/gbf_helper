# ルシフェル(Lucifer)

## 概要

Providenceシリーズの光属性召喚石。加護効果は光属性攻撃力アップ、召喚効果は敵全体への大ダメージと味方全体の攻撃力アップを兼ねる、光属性の代表的な攻刃枠召喚石。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| レアリティ | SSR |
| 属性 | 光 |
| 入手方法 | プレミアムガチャ/クラシックガチャ排出(サプライズチケット交換不可) |

| レベル | HP | ATK |
| --- | --- | --- |

| Lv150(4★・最終上限解放) | 1280 | 2850 |

## 召喚効果

- 効果: 敵全体に光属性ダメージ(特大)。味方全体の攻撃力をUP(大)。
- 数値/スケーリング: 4凸で味方全体のHP回復効果が追加される。
- 出典: GameWith

## 加護効果(メイン編成時)

- 効果: 光属性の攻撃力UP。
- 数値/スケーリング: 基本100%UP、(3凸)120%UP、(4凸)130%UP。
- 出典: GameWith

## サブ加護効果(サブ編成時)

- 加護効果と同一(倍率のみ半分程度になる想定、GameWith一覧には明記なし、要検証)。
