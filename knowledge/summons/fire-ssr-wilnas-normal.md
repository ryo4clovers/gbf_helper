## 召喚効果

### 初期『ハドロン･スフィア』

- 効果: 火属性1.5倍ダメ(上限約4.85万)×15回 / 火属性キャラの与ダメージ上昇(最大75,000)×1ターン / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 最大『ハドロン･スフィア』

- 効果: 火属性1.5倍ダメ(上限約4.85万)×15回 / 火属性キャラの与ダメージ上昇 (最大100,000)×1ターン / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸『ハドロン･スフィア』

- 効果: 火属性1.5倍ダメ(上限約4.85万)×15回 / ・火傷Lvが1上昇(最大10/回復不可)×180秒 / └毎ターンHP1万ダメ×火傷Lv(最大10万) / 火属性キャラの与ダメージ上昇 (最大100,000)×1ターン / ◆参戦者が合体召喚不可 / ※15回ダメには与ダメ加算･上限UP適用不可/天司系のみ○
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

## 加護効果(メイン編成時)

- 効果: 火属性攻撃力が100%UP / (3凸)火攻撃UPが120%に強化 / (4凸)火属性攻撃力が140%UP
- 出典: GameWith。4凸部分はユーザー提供のゲーム内deckレスポンス
- ステータス: 4凸部分は検証済み(2026-09-09)

## サブ加護効果(サブ編成時)

- 効果: (4凸)スキル「火」「業火」「紅蓮」の効果が40%UP
- 数値/スケーリング: 通常スキル加護へ40%を加算する。メイン・サポートのLv250・6★アグニス各170%とオプティマスブースト30%を含む編成では、通常スキル強化量が370%から410%へ増加した。
- 出典: ユーザー提供のゲーム内deckレスポンス2件(ウィルナスあり/なし、確認日: 2026-09-09)
- ステータス: 検証済み
