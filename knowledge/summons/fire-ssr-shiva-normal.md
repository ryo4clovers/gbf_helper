## 召喚効果

### 初期『第三の目、開眼』

- 効果: 敵全体に火属性ダメージ(特大) / 味方全体に『破壊の導き(攻撃大幅UP/1回)』 / 【破壊の導き効果】 / ・攻撃力100%UP(別乗算･いつアサ系) / └通常ダメ上限116万迄上昇/奥義ダメ上限値に50万加算 / ◆再召喚不可
- 使用間隔: 12ターン
- 再召喚: 不可
- 出典: GameWith(個別ページ)

### 4凸『第三の目、開眼』

- 効果: 敵全体に火属性5倍ダメージ(上限約112万) / 味方全体に / ・破壊の導き(攻撃大幅UP/1回) / ・トリプルアタック確率100%UP×1ターン / 【破壊の導き効果】 / ・攻撃力100%UP(別乗算･いつアサ系) / └通常ダメ上限116万迄上昇/奥義ダメ上限値に50万加算 / ◆再召喚不可 / ※確定TAでは無い100%UPだが、他の召喚確定TA枠(水着ティアマトサブ加護)を上書きするのを確認
- 使用間隔: 9ターン
- 再召喚: 不可
- 出典: GameWith(個別ページ)
