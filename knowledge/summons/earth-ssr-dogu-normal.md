## 召喚効果

- 効果: 敵全体に土属性5倍ダメージ / 土属性キャラに荒土の刻印を付与(最大5/消去不可) / 3ターンの間、土属性攻撃UP / ◆参戦者が合体召喚不可 / (3凸)敵全体に土属性7倍ダメージ / 土属性キャラに荒土の刻印を付与(最大5/消去不可) / 3ターンの間、土属性攻撃UP / ◆参戦者が合体召喚不可 / (4凸)9倍ダメージ / 土属性攻撃力UPが60%に強化 / 敵全体に石化効果(個別/1~2T)
- 出典: GameWith

## 加護効果(メイン編成時)

- 効果: 土属性攻撃力が50%UP / (3凸)土属性攻撃力が80%UP / (4凸)土属性攻撃力100%UP / バトル開始時に味方全体に荒土の刻印を付与 / サブ加護:最大35%UP
- 出典: GameWith

## サブ加護効果(サブ編成時)

- 効果: 土属性キャラがそれぞれの荒土の刻印の数に応じて土属性攻撃力UP / (3凸)土属性キャラがそれぞれの荒土の刻印の数に応じて土属性攻撃力UP
- 出典: GameWith
