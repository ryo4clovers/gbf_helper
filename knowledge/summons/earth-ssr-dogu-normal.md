## 召喚効果

### 初期『ギガ･ジョーモン･カノン』

- 効果: 敵全体に土属性5倍ダメージ(上限約63万) / 土属性キャラに荒土の刻印を付与(最大5/消去不可) / 3ターンの間、土属性攻撃25%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 3凸

- 効果: 敵全体に土属性7倍ダメージ(上限約63万) / 土属性キャラに荒土の刻印を付与(最大5/消去不可) / 3ターンの間、土属性攻撃50%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

### 4凸

- 効果: 敵全体に土属性9倍ダメージ(上限約70万) / 水属性の敵に石化効果(個別/1~2ターン) / ※基本弱体成功率100% / ※石化中は敵へのダメージ2.2倍 / ※別乗算攻撃120%UPと同等の効果 / 土属性キャラに荒土の刻印を付与(最大5/消去不可) / 3ターンの間、土属性攻撃60%UP / ◆参戦者が合体召喚不可
- 初回召喚: 3ターン後
- 使用間隔: 9ターン
- 再召喚: 可
- 出典: GameWith(個別ページ)

## 加護効果(メイン編成時)

- 効果: 土属性攻撃力が50%UP / (3凸)土属性攻撃力が80%UP / (4凸)土属性攻撃力100%UP / バトル開始時に味方全体に荒土の刻印を付与 / サブ加護:最大35%UP
- 出典: GameWith

## サブ加護効果(サブ編成時)

- 効果: 土属性キャラがそれぞれの荒土の刻印の数に応じて土属性攻撃力UP / (3凸)土属性キャラがそれぞれの荒土の刻印の数に応じて土属性攻撃力UP
- 出典: GameWith
