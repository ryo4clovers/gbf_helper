# ナレッジ文書のローカル画像

ジョブ・武器の本文画像とアビリティアイコンを公開CDNの静的画像からローカル保存し、本文から相対パスで参照します。ゲームAPI・認証通信は使用しません。画像取得ではナレッジの数値や検証ステータスを変更しません。

画像は `cdn/` 以下に保存します。gitignore対象のローカル専用で、コミット・再配布しません。`manifest.json` に元URL、参照文書、保存先、サイズ、SHA-256、取得日時を残します。

リポジトリルートで次を実行します。

```powershell
node scripts/localize-knowledge-images.mjs --scan   # 対象確認、通信なし
node scripts/localize-knowledge-images.mjs --apply  # 保存・参照変換、再開・復元にも使用
node scripts/localize-knowledge-images.mjs --verify # オフラインで相対参照・画像・ハッシュを検証
```

未保存・破損画像だけを直列で取得します。取得開始は最低1.5秒間隔、タイムアウト15秒、各画像は最大1MiBです。リダイレクト・登録外ホスト・ゲームAPI・不正画像形式を拒否します。失敗分は元の参照とmanifestのerrorに残し、同じ実行中には自動再試行しません。

新しいcheckoutでもapplyコマンドで画像を復元できます。保存済み画像はオフラインで読み取れます。文書追加時はテンプレートの相対パスへ画像を配置するか、一時的に公開CDNの画像参照を記入して同コマンドで保存・変換してください。出典URLは固定CDNの画像パスに限定して検証します。取得するプロセスを複数同時起動しないでください。
