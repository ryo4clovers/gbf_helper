# アダム(Adam)

## 概要

自身HP80%以上を維持することで自身と土属性の味方を強化できるキャラ。1万バリアや70%カットなどで味方HP維持に貢献でき、2回発動ディスペルで強化対策役もこなせるため、対強敵で活躍が見込める。

## スキル構成

### アビリティ1: インドマタビリティ(Lv55短縮)

- 効果: 土属性キャラにバリア効果と「エイド」効果(消去不可、2回被ダメージで解除)を付与する。エイドは奥義ダメージ・奥義上限アップと高揚効果を含む。
- 数値/スケーリング: バリア(耐久10000)。奥義ダメージ+30%/奥義上限+10%。高揚+10%。
- CT(クールタイム): 18ターン(Lv55で16ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: アトウンメント(Lv75短縮)

- 効果: 敵に土属性ダメージを与え、敵の強化効果を1つ無効化する。アキレア効果中は2回発動する。
- 数値/スケーリング: 倍率7倍(上限約73万)。
- CT(クールタイム): 7ターン(Lv75で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: ラディアント・イージス(Lv45で習得)

- 効果: 味方全体に水属性ダメージカットを付与する。
- 数値/スケーリング: 水属性ダメージ-70%(2ターン)。
- CT(クールタイム): 8ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: オナー・オブ・エルステ

- 効果: 敵に土属性ダメージを与える。自身のHPを回復し、ブロック効果を付与する。アキレア効果中は奥義性能もアップする。
- 数値/スケーリング: 倍率4.5倍。HP回復+20%(上限4000)。ブロック(被ダメージ30%軽減、発動率100%、2ターン)。奥義ダメージ+50%/奥義上限+25%(アキレア中)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 宰相の務め: バトル開始時に自身へ「アキレア」効果を付与する(消去不可、1ターン)。ターン終了時、HPが80%以上の場合も自身にアキレアを付与する。アキレア効果中は土属性キャラの攻撃・防御・DA率・TA率をアップする。
- 数値/スケーリング: 攻撃+30%(別乗算、久遠枠)。防御+50%。DA率+30%/TA率+15%。
- 究極のゴーレム: 敵から受ける水属性ダメージの最大値を固定する。
- 数値/スケーリング: 水属性ダメージ上限5000固定。
