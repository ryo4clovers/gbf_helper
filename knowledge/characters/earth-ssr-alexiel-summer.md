# 水着ブローディア(Alexiel (Summer))

## 概要

味方全体の防御を永続で強化し、全体かばう+属性変換+最大ダメージ1500固定でパーティを守れる壁役。奥義後自動発動する追加ダメージアビリティで奥義周回編成などでも活躍できる性能。

## スキル構成

### アビリティ1: 不可侵海域(Lv55短縮)

- 効果: 自身の弱体効果を全て回復し、自身に防御UP・弱体耐性UP・水属性変転効果・被ダメージ上限固定・全体かばう効果を付与する(消去不可、毎ターン刃鏡を消費し0で解除、最大3ターン)。
- 数値/スケーリング: 防御+300%。弱体耐性+100%。受ける水属性ダメージ最大値1500固定(全体攻撃時は1500×4人分で最大6000)。
- CT(クールタイム): 8ターン(Lv55で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: ヒルデブランド(Lv75短縮)

- 効果: 敵全体に土属性ダメージを与え、味方に防御UP(累積・永続・消去不可)を付与する。自身に刃鏡を付与する。
- 数値/スケーリング: 倍率4倍(上限約63.5万)。防御+9%(累積、最大45%、永続、消去不可)。刃鏡+1。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: ニーベルン・ザント(Lv45で習得)

- 効果: 敵全体に水属性攻撃ダウンと最大CT増加を付与する。刃鏡1消費で命中率ダウンを追加付与する。
- 数値/スケーリング: 水属性攻撃-20%(180秒)。最大CT増加(180秒)。刃鏡消費時追加: 命中率-約50%(2ターン)。いずれも基本弱体成功率100%。
- CT(クールタイム): 6ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: 刃鏡螺旋

- 効果: 敵に土属性ダメージを与え、自身に「絶対魔滅」を付与する(消去不可、ターン終了時にヒルデブランド(2アビ)が発動)。
- 数値/スケーリング: 倍率4.5倍。絶対魔滅(2ターン)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 刃鏡燦然: 刃鏡の数に応じて攻防をアップする(バトル開始時刃鏡3、最大5)。刃鏡が3つ以上の時は再生効果も得る。
- 数値/スケーリング: 攻撃+10%×刃鏡数(最大50%、別枠乗算)。防御+10%×刃鏡数(最大50%)。再生(最大HP10%回復、最大1000)。
- 全力のバカンス: 不可侵海域展開中、防御UP・弱体耐性UP・全体かばう効果・被ダメージ水属性変換(最大値1500固定)を得る。
