# ダーント(R)(Dante)

## 概要

2アビで氷刃状態に攻撃性能が上がるアタッカー。HPが減るデメリットがあるので短期戦での起用が考えられる。キャットラバーウィザード。

| 項目 | 内容 |

| 属性 | 火 |
| 種族 | ヒューマン |
| タイプ | 攻撃/杖 |
| 入手方法 | レジェンドガチャ(宿樹の仙杖入手で解放) |

## スキル構成

### アビリティ1: エーテルキャスト(Lv45で性能強化)

- 効果: 敵に火属性ダメージを与える(氷刃状態の時に1~10倍水属性追加ダメージ)。
- CT(クールタイム): 9ターン。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP960/ATK3200)

### アビリティ2: アンリーシュ(Lv25で習得)

- 効果: 自分に氷刃効果を付与する(再使用で氷刃効果消滅)。
- CT(クールタイム): 1ターン。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP960/ATK3200)

### 奥義: リべレーション・フレイム

- 効果: 敵に火属性ダメージを与える(自分のHPが少ないほど奥義ダメージUP)。
- 数値/スケーリング: 倍率(大)。
- 出典: GameWith

### サポートスキル(常時発動)

- オフセットパワー: 氷刃時にダブルアタック確率をUP(特大)する代わりに毎ターン自分にダメージを与える。
