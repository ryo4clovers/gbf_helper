# ミュオン(クリスマス)(Meteon (Holiday))

## 概要

通常時は連撃が発生しないが通常攻撃/奥義ともにダメージが高く、通常攻撃後の追加ダメも持つ優秀なアタッカー。自動発動全体アビを使ったイベント周回時の雑魚狩りや、高威力奥義を活かした奥義周回などで活躍する。

## スキル構成

### アビリティ1: ボディ・ブレイクダウンII(Lv55短縮)

- 効果: 敵に風属性ダメージを与え、防御DOWN、風属性防御DOWN、弱体耐性DOWNを付与する。
- 数値/スケーリング: 倍率1.0~1.5倍(上限約21万)×3回。防御-15%DOWN(アマブレ、片面枠、180秒、基本弱体成功率100%)。風属性防御-20%DOWN(180秒、基本弱体成功率90%)。弱体耐性-10%DOWN(180秒、基本弱体成功率100%)。防御→風防御→弱体耐性の順で判定。
- CT(クールタイム): 7ターン(Lv55で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ2: ミラージュダイブ(Lv75短縮)

- 効果: 敵の全ての攻撃を回避し、ターン経過なしで通常攻撃を実行する。
- 数値/スケーリング: 全回避(1回、消費まで永続)。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ3: ナイトロバースト(Lv45で習得、流星Lv2消費)

- 効果: ナイトロバースト状態に移行する(消去不可)。
- 数値/スケーリング: 必ずトリプルアタック。クリティカル率UP(倍率30%/発動100%)。アビダメUP(倍率1.0倍加算)。アビダメ上限+50%UP。弱体効果無効化。5ターン。
- CT(クールタイム): 10ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### 奥義: ホーリーナイト・ソニック

- 効果: 敵に風属性ダメージを与え(サポアビの強化込み)、自身の流星Lvを上昇させる。
- 数値/スケーリング: 倍率10.5倍(サポアビ込み)。流星Lv+1(最大2、消去不可)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### サポートスキル(常時発動)

- ビヨンド・ザ・スピード: 通常攻撃与ダメUP、奥義倍率・上限強化、回避率UPを持つ。通常攻撃後、敵全体に追加ダメージを与え自分の奥義ゲージをUPする。
- 数値/スケーリング: 通常攻撃与ダメ+50%UP(天司枠加算)。奥義倍率10.5倍に強化。奥義上限+30%UP。回避率+約30%UP。通常攻撃後: 風属性5.0倍ダメ(上限約63万)。奥義ゲージ+10%UP。
- ナイトロ・リミッター: 連続攻撃が発生しない(3アビ中以外)。ナイトロバースト状態中は自分の性能が強化される(3アビ効果を反映)。他キャラによるTA100%付与でも連撃は発動しない。
