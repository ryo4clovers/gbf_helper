# コルワ(浴衣)(Korwa (Yukata))

## 概要

2種類の「フィル」ゲージを消費して、前方配置キャラへの防御支援と次配置キャラへの火力支援を使い分ける支援型キャラ。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| レアリティ | SSR |
| 属性 | 光 |
| 種族 | エルーン |
| タイプ | 特殊 |
| 入手方法 | サマープレミアム引換(ガチャ、武器「ハッピーエンドクィル」入手で開放) |

## スキル構成

### アビリティ1: アン・ティスュ・ブルー

- 効果: 「フィル・ブルー」を10消費して、自分の前に配置された光属性キャラにかばう効果・弱体耐性アップ・ブロック効果(被ダメージ軽減)を付与する。2回発動でカウンター効果、3回発動で不死身効果も追加。
- 数値/スケーリング: かばう(全体、延長不可)×2ターン、弱体耐性+100%×2ターン、ブロック(被ダメ50%軽減、発動率100%)×2ターン。2回目: 被ダメ時に全力カウンター(6回)×2ターン。3回目: 不死身1回。
- CT(クールタイム): 2ターン(Lv55で1ターンに短縮)。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### アビリティ2: アン・ティスュ・ロゼ

- 効果: 「フィル・ロゼ」を10消費して、自分の次に配置された光属性キャラにトリプルアタック確率アップ・光属性追撃・乱撃(3ヒット)を付与する。2回発動で攻撃大幅アップ、3回発動でターン経過なし通常攻撃も追加。
- 数値/スケーリング: TA確率+100%×2ターン、光属性追撃+50%×2ターン、乱撃(3ヒット)×2ターン。2回目: 攻撃+50%(いつアサ系)×1ターン(通常ダメージ上限116万まで上昇、奥義ダメージ上限に50万加算)。
- CT(クールタイム): 2ターン(Lv75で1ターンに短縮)。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### アビリティ3: マキヤージュ(Lv45で習得)

- 効果: 自身が即座に奥義発動可能になり、回復性能がアップする(累積)。
- 数値/スケーリング: 回復性能+20%(累積最大60%)。
- CT(クールタイム): 5ターン。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### 奥義: ブランシェ・フィル

- 効果: 光属性キャラ全体のHPを回復し、弱体効果を1つ回復、ディスペルガード効果、光属性攻撃アップ、ダメージ上限アップを付与する。自身の「フィル・ブルー」と「フィル・ロゼ」を1回復。
- 数値/スケーリング: HP回復(最大3000)、光属性攻撃+10%(累積最大50%)、ダメージ上限+3%(累積最大15%)。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### サポートスキル(常時発動)

- こだわりの装い: ターン終了時にフィル・ブルーが1回復(最大10、バトル開始時10)。自分の前に配置された光属性キャラが敵の攻撃対象になった場合もフィル・ブルーが1回復。
- 夏のインスピレーション: ターン終了時にフィル・ロゼが1回復(最大10、バトル開始時10)。自分の次に配置された光属性キャラが累計で攻撃行動2回以上行った場合のターン終了時もフィル・ロゼが1回復。
