# 闇ロベリア(バレンタイン)(Lobelia (Valentine))

## 概要

バトル開始時の刻印+1がマナダイバー運用と好相性のアビアタッカー。3アビ発動後は味方耐久強化+アビ/通常攻撃毎に追加ダメを得られ、毎ターン使用可能な確定TA+6回ダメ+ゲージ支援、固有Lv10消費で強化3つ消去+味方回復もこなせる。刻印頻度さえ用意できれば攻防に貢献するアビアタッカー。

## スキル構成

### アビリティ1: アビサルスパーク(リンクアビで連動、Lv補正なし)

- 効果: 敵に闇属性ダメージを6回与え、闇属性キャラの奥義ゲージをUPし、自分に確定トリプルアタックと幽闇の刻印を付与する。
- 数値/スケーリング: 倍率1.0倍(1回あたり上限約7.4万)×6回。奥義ゲージ+10%UP。トリプルアタック確率+100%UP(1回)。幽闇の刻印+1(最大5、消去不可)。
- CT(クールタイム): 1ターン(リンクアビで連動)。
- 出典: GameWith / gbf.wiki(整合、6-hit 100%、Damage cap: ~74,000 per hit、Charge Bar +10%、100% TA Up、1 Oblivion Crest)
- ステータス: 両ソース一致

### アビリティ2: ハーモニックインパクト(スウィート・シェル10消費、リンクアビで連動、Lv補正なし)

- 効果: タゲに関わらず闇属性ダメージを10回与え、敵全体のDA/TA確率をDOWNさせ、強化効果を3つ無効化する。闇属性キャラのHPも回復する。
- 数値/スケーリング: 倍率1.0倍(1回あたり上限約10.8万)×10回。DA確率-100%DOWN(3ターン)。TA確率-100%DOWN(3ターン)。強化効果3つ無効化。HP50%回復(最大4000)。
- CT(クールタイム): 1ターン(リンクアビで連動)。
- 出典: GameWith / gbf.wiki(整合、10-hit 100%、Damage cap: ~108,000 per hit、100% DA/TA Down、Remove 3 buffs)
- ステータス: 両ソース一致

### アビリティ3: ウィズアウト・エンド(Lv45で習得、スウィート・シェル7消費、再使用不可)

- 効果: 闇属性キャラに禍殃の偏愛効果(永続・消去不可)を付与する。アビリティ再使用間隔も短縮する。
- 数値/スケーリング: 禍殃の偏愛効果: 防御+50%UP、ブロック効果(被ダメ20%軽減)、アビリティ与ダメージ+5万上昇、アビ使用時に敵へ闇ダメ(上限約45万)、通常攻撃後に敵へ闇2.0倍ダメ(上限約30万)。アビリティ再使用間隔-3ターン短縮。
- 出典: GameWith / gbf.wiki(整合、Disastrous Devotion、3-turn cut to skill cooldowns)
- ステータス: 両ソース一致

### 奥義: ラ・ベルスーズ・デュボヌール

- 効果: 敵に闇属性ダメージを与え、追加ダメージと防御DOWNを付与する。禍殃の偏愛効果中は2回発動する。
- 数値/スケーリング: 倍率4.5倍(上限約168.5万)。闇属性5.0倍追加ダメージ(上限約63.5万)。防御-10%DOWN(累積最大40%、180秒)。
- 出典: GameWith / gbf.wiki(整合、450% Massive Dark damage、500% Bonus Dark damage、Damage cap: ~635,000)
- ステータス: 両ソース一致

### サポートスキル(常時発動)

- 災愛の声音: 自分に幽闇の刻印付与時、自分にスウィート・シェルが付与される(最大10、消去不可)。致死ダメージを受けた時、幽闇の刻印3消費してそのターン中はHP1で耐える。
- 数値/スケーリング: スウィート・シェル+1(最大10、消去不可)。
- 歪んだ渇望: バトル開始時に闇属性キャラに幽闇の刻印+1を付与する。闇キャラが幽闇の刻印数に応じてアビ性能がUPする(自分がサブメンバーにいる場合でも発動)。
- 数値/スケーリング: アビダメ倍率+0.1倍加算×刻印数(最大0.5倍加算)。アビ上限+2%UP×刻印数(最大10%)。
