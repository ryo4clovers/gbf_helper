# 水着シャトラ(Catura (Summer))

## 概要

各アビリティで自分と主人公の攻守両面を大きく強化できるキャラ。自身と主人公がTAでディスペル付き8倍ダメ、5ターン続く通常与ダメUP+TA率UPに加え、自身と主人公が合計4回行動で攻撃大幅UPなど通常軸編成で活躍する。

## スキル構成

### アビリティ1: 三思九丑(Lv55で使用間隔短縮、使用回数に応じ性能UP最大3回)

- 効果: 自分と闇属性の主人公のトリプルアタック確率・通常攻撃与ダメージをUPし、ブロック効果とHP回復を付与する。3回発動でターン経過なしの通常攻撃も可能になる。
- 数値/スケーリング: 1回目: TA率+30%、通常攻撃与ダメ+10%UP、ブロック30%軽減、HP回復3000。2回目: TA率+40%、通常攻撃与ダメ+20%UP、ブロック40%軽減、HP回復6000。3回目: TA率+50%、通常攻撃与ダメ+30%UP、ブロック50%軽減、HP回復12021(各5ターン)。
- CT(クールタイム): 14ターン(Lv55で12ターンに短縮)。
- 出典: GameWith / gbf.wiki(整合、TA Up・DMG Amplified・Armored、5ターン)
- ステータス: 両ソース一致

### アビリティ2: 噴射水筒(Lv75で使用間隔短縮)

- 効果: 敵に闇属性ダメージを与え、強化効果を1つ無効化し、闇属性防御をDOWNさせる。闇属性キャラにテンションUPも付与する。
- 数値/スケーリング: 倍率8.0倍(上限約102万)。闇属性防御-10%DOWN(累積最大40%、180秒)。テンションUP(2ターン)。
- CT(クールタイム): 9ターン(Lv75で8ターンに短縮)。
- 出典: GameWith / gbf.wiki(整合、800% Dark damage、Damage cap: ~1,020,000)
- ステータス: 両ソース一致

### アビリティ3: 猛夢丑(Lv45で習得、バトルメンバーに主人公がいる時のみ使用可能)

- 効果: 自分に潮の丑神効果(消去不可・延長不可)を付与し、闇属性の主人公に潮の王子効果(消去不可・延長不可)を付与する。両効果とも被ダメ時にカウンターと追加ダメージを発揮する。
- 数値/スケーリング: 潮の丑神効果(2ターン): 潮の王子中の主人公がかばうダメージの半分を肩代わり、被ダメ時に全力3倍カウンター(2回)、カウンター時に闇属性5倍追加ダメ(上限約65万)。潮の王子効果(2ターン): 全体かばう、被ダメージを光属性に変換、光属性ダメージ-50%軽減、被ダメ時に全力3倍カウンター(2回)、カウンター時に闇属性5倍追加ダメ(上限約65万)。
- CT(クールタイム): 12ターン。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki側の当該部分は未取得)

### 奥義: 五心不乱

- 効果: 敵に闇属性ダメージを与え、闇属性キャラに闇属性追撃効果を付与し、自分のアビ再使用間隔を短縮する。
- 数値/スケーリング: 倍率4.5倍(上限約168.5万)。闇属性+10%追撃効果(4ターン)。アビ再使用間隔-2ターン短縮。
- 出典: GameWith / gbf.wiki(整合、450% Massive Dark damage、10% Bonus Dark DMG、3.5 turns)
- ステータス: 両ソース一致

### サポートスキル(常時発動)

- 海辺の丑神: 同一ターン中に自分と闇属性の主人公がTA時、ターン中に1回、噴射水筒(2アビ)が発動し、王子さまへの想いLvが上昇し、アビ再使用間隔が短縮される。王子さまへの想いLvに応じて闇属性キャラの攻防・アビ倍率・アビ上限がUPする。
- 数値/スケーリング: 王子さまへの想いLv+1(最大5、消去不可)。アビ再使用間隔-1ターン短縮。Lvに応じ: 攻撃+6%UP×Lv(最大30%、久遠枠加算)、防御+10%UP×Lv(最大50%)、アビ倍率+0.1倍加算×Lv(最大0.5倍加算)、アビ上限+2%UP×Lv(最大10%)。
- 王子さまとのバカンス: 自分と闇属性の主人公がターン中に累計で攻撃行動4回以上行ったターン終了時、両者に攻撃大幅UP(1回)を付与する。
- 数値/スケーリング: 攻撃+50%UP(1回、1ターン、通常ダメ上限116万まで上昇、奥義ダメ上限値+50万加算)。
