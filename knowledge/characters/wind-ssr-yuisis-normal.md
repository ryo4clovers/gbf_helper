# ユイシス(Yuisis)

## 概要

アビリティで「星薙の型(剣盾モード)」/「天終の型(両手剣モード)」という2つのフォームを切り替え可能で、フォームごとに異なった強みを発揮するキャラ。星薙の型では敵の攻撃から味方を守ることが可能で、天終の型では奥義中心に高い火力を誇るアタッカーとして活躍できる。

## スキル構成

### アビリティ1: 不忠への報い/断固たる定見(Lv55短縮)

- 効果: 星薙の型(剣盾モード)/天終の型(両手剣モード)に変更する。
- CT(クールタイム): 1ターン(Lv55で0ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ2: 一刀専心(天終の型、Lv75短縮、Lv95で性能強化、最大HP20%消費)

- 効果: 自分に専心効果(消去不可)を付与し、奥義ゲージをUPする。
- 数値/スケーリング: 攻撃+200%UP(別枠乗算、1ターン、Lv95後)。奥義上限+100%UP(1ターン、Lv95後)。奥義ダメージ特殊上限+50%UP(1ターン、Lv95後)。奥義バースト効果(Lv95後)。
- CT(クールタイム): 6ターン(Lv75で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ2: 杯の庇護(星薙の型、Lv75短縮、Lv95で性能強化、奥義ゲージ20%消費)

- 効果: 自分にかばう効果、全属性ダメージカット、弱体効果無効を付与する。Lv95以降は全体かばう+被ダメージ土属性変換も追加される。
- 数値/スケーリング: 全体かばう(1ターン、Lv95後)。全属性ダメージ70%カット(1ターン)。弱体効果無効(1回)。被ダメージ土属性変換(3ターン、Lv95後)。
- CT(クールタイム): 6ターン(Lv75で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ3: 仇花散華(天終の型、Lv45で習得)

- 効果: 自分に必ずダブルアタック以上と高揚効果を付与する。
- 数値/スケーリング: 必ずDA以上(3ターン)。高揚効果(奥義ゲージ+10%UP、3ターン)。
- CT(クールタイム): 5ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ3: 叛意即斬(星薙の型、Lv45で習得)

- 効果: 自分にカウンター効果と土属性被ダメ軽減を付与する。
- 数値/スケーリング: 2.5倍カウンター(被ダメ時、2回、3ターン)。土属性被ダメ-30%軽減(3ターン)。
- CT(クールタイム): 5ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ4: 彩花の契り(Lv100で習得、フォームにより効果が異なる)

- 効果(天終の型): 自分に風属性攻撃UP、追撃、クリティカル確率UP、ダメージ上限UPを付与し、侠気Lvを上昇させる。
- 数値/スケーリング: 風属性攻撃+50%UP(5ターン)。風属性追撃+50%(5ターン)。クリティカル確率UP(倍率20%/発動100%、5ターン)。ダメージ上限+20%UP(5ターン)。侠気Lv+2。
- 効果(星薙の型): 自身のHPと弱体を全回復し、他のアビリティを即時使用可能にする。
- CT(クールタイム): 12ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### 奥義: 破煌刃・神薙(天終の型、最終後)/破煌刃・暁天(星薙の型、最終後)

- 効果(天終の型): 敵に風属性ダメージを与え、侠気Lvに応じた追加ダメージを与える。自分に追撃効果と侠気Lv上昇を付与する。
- 数値/スケーリング: 倍率5.0倍(最終後、上限168.5万)。侠気Lv応じ風属性1倍ダメ(上限約11万、最大5回)。風属性追撃+50%(4ターン)。侠気Lv+1(最大5、消去不可)。
- 効果(星薙の型): 敵に風属性ダメージを与え、自分に吸収効果と被ダメージ吸収を付与する。
- 数値/スケーリング: 倍率5.0倍(最終後)。吸収効果(最大1000回復、4ターン)。被ダメージ30%吸収(4ターン)。侠気Lv+1(最大5、消去不可)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### サポートスキル(常時発動)

- ディートリア流剣術・天終の型: 天終の型時、攻撃UP・敵対心DOWN・強化効果消去無効を得る。侠気Lvに応じて奥義ダメ・上限もUPする。
- 数値/スケーリング: 攻撃+30%UP(別枠乗算、久遠枠加算)。奥義ダメ+15%UP×Lv(最大75%)。奥義上限+5%UP×Lv(最大25%)。
- ディートリア流剣術・星薙の型: 星薙の型時、防御UP・敵対心UP・活性効果を得る。侠気Lvに応じて奥義ゲージ上昇量・回復性能もUPする。
- 数値/スケーリング: 防御+50%UP。活性効果(HP5%回復最大500、回復しない時奥義ゲージ+10%UP)。奥義ゲージ上昇量+10%UP×Lv(最大50%)。回復性能+20%UP×Lv(最大100%)。
- 忠義の魔具(Lv90で習得): バトル開始時、配置順に応じて効果が変化する。
- 数値/スケーリング: 1・3番目: 不死身効果(3回)。2・4番目: 侠気Lv+2、天終の型状態でバトル開始。
