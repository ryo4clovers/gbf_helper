# 水アリーザ(SR)(Aliza (Water))

## 概要

奥義後の2ターン追撃に加えて、ストレングス(残りHPが多いほど攻撃UP)を持つアタッカー。全てのアビリティにクセがなく、どんなプレイヤーでも使いやすい。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| レアリティ | SR |
| 属性 | 水 |
| 種族 | ドラフ |
| タイプ | 攻撃/格闘 |
| 入手方法 | サイドストーリー『サウザンド・バウンド』1話エピソード2クリアで加入 |

## スキル構成

### アビリティ1: 発勁(Lv45で性能強化)

- 効果: 敵全体に水属性ダメージを与える(上限約28万)。敵の数が少ないほどダメージがUPする。
- CT(クールタイム): 6ターン。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP810/ATK6490)

### アビリティ2: 華焔・水紋(Lv65で使用間隔短縮)

- 効果: 自分のHPを回復し、3ターンの間、奥義ダメージUP(1回)を付与する。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP810/ATK6490)

### アビリティ3: 剛脚烈破(Lv35で習得)

- 効果: 敵に水属性ダメージを与える(上限約40万)。3ターンの間、自分の残りHPが多いほど攻撃が大きくUPする。
- CT(クールタイム): 8ターン。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP810/ATK6490)

### 奥義: 蒼炎嵐翔

- 効果: 敵に水属性ダメージを与え、2ターンの間、水属性追撃効果を付与する。
- 数値/スケーリング: 倍率(大)。
- 出典: GameWith

### サポートスキル(常時発動)

- 静かなる闘志: 自分の残りHPが多いほどダブルアタック確率がUPする。
