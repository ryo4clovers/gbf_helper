# ヴィーラ(Vira)

## 概要

自己バフと妨害を兼ねる闇属性の攻撃型キャラクター。カタリナが編成にいると強化されるサポートスキルを持つのが特徴。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| レアリティ | SR |
| 属性 | 闇 |
| 種族 | ヒューム |
| タイプ | 攻撃 |
| 入手方法 | プレミアム引換(ガチャ)で入手 |

## スキル構成

### アビリティ1: レイヤーライズ(Layer Rise)

- 効果: 自身に攻撃力アップを付与し、敵単体に攻撃力ダウンを付与する。Lv45到達後は効果が強化される。
- 数値/スケーリング: 要検証(具体的な%は未取得)。
- CT(クールタイム): 6ターン(Lv45で5ターンに短縮)。
- 持続時間: 3ターン/180秒。
- 出典: https://gbf.wiki/Vira
- ステータス: 未検証

### アビリティ2: ライフスティール(Life Steal)

- 効果: 敵単体に闇属性ダメージを与え、自身のHPを回復する。Lv65到達後は効果が強化される。
- 数値/スケーリング: 回復量上限1000。
- CT(クールタイム): 9ターン(Lv65で8ターンに短縮)。
- 持続時間: -
- 出典: https://gbf.wiki/Vira
- ステータス: 未検証

### アビリティ3: ダーケイン(Darkane)

- 効果: 自身に確定TA(トリプルアタック)を付与。
- 数値/スケーリング: -
- CT(クールタイム): 8ターン。
- 持続時間: 1ターン。
- 出典: https://gbf.wiki/Vira
- ステータス: 未検証

### 奥義: ブレイドオブアーダー(Blades of Ardor)

- 効果: 敵単体に闇属性ダメージ。
- 数値/スケーリング: 大ダメージ(具体的な倍率は未取得)。
- 出典: https://gbf.wiki/Vira
- ステータス: 未検証

### サポートスキル(常時発動)

- オー・カタリナ: 編成内にカタリナ(バージョン問わず、サブ枠含む)がいる場合、自身のATK・DEFがアップ。
- EMP(奥義マスタリー): 編成内にカタリナがいる場合、自身の多段攻撃率がアップ(ランクにより変動)。
