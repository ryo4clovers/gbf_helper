# ヴィーラ(SR)(Vira)

## 概要

攻撃UPと確定トリプルアタックが特徴のシンプルなアタッカー。特性上奥義ゲージを溜める速度も早い。アビリティの構成は悪くないのだが、全体的に使用間隔が長く、扱いにくい部分があるのは気になるところ。狂奔の忠騎。

## スキル構成

### アビリティ1: レイヤーライズ(Lv45で性能強化・使用間隔短縮)

- 効果: 敵の攻撃をDOWNさせ、3ターンの間自分の攻撃をUPする。
- CT(クールタイム): 6ターン(Lv45で5ターンに短縮)。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP1000/ATK7000)

### アビリティ2: ライフスティール(Lv65で性能強化・使用間隔短縮)

- 効果: 敵に闇属性ダメージを与え、自分のHPを回復する。
- CT(クールタイム): 9ターン(Lv65で8ターンに短縮)。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP1000/ATK7000)

### アビリティ3: ダーケイン(Lv35で習得)

- 効果: 1ターンの間、必ずトリプルアタックになる。
- CT(クールタイム): 8ターン。
- 出典: GameWith
- ステータス: GameWith/gbf.wikiで一致(HP1000/ATK7000)

### 奥義: リストリクションズ・ネイル

- 効果: 敵に闇属性ダメージを与える。
- 数値/スケーリング: 倍率(大)。
- 出典: GameWith

### サポートスキル(常時発動)

- カタリナお姉様…: カタリナがパーティにいる場合に自身の攻撃UP/防御UPする。
