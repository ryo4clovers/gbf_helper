# ヴァンピィ(Vania)

## 概要

魅了、CT吸収、ディスペルなどで敵を弱体化しつつ、ダメアビや魅了中の高威力奥義で火力にも貢献するキャラ。特に序盤はディスペル持ちとして対シュヴァマグ戦で役立つ。最終後は火力性能が大幅強化され、アタッカーとしても活躍できる。種族はヴァンパイアだがゲーム内では不明扱い。

## スキル構成(バランス調整後・最終上限解放後)

### アビリティ1: テスタメント++(Lv55で性能強化・使用間隔短縮、Lv100で性能強化)

- 効果: 敵に闇属性ダメージを与え、強化効果を1つ無効化する。ヴァンパイアブラッド消費で闇属性防御DOWNを追加できる。
- 数値/スケーリング: 倍率6~7倍(上限約80万)。強化効果1つ無効化。闇属性防御-25%DOWN(180秒、基本弱体成功率100%、VB消費時)。
- CT(クールタイム): 8ターン(Lv55で7ターン、Lv100で6ターンに短縮)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki側の当該部分は未取得)

### アビリティ2: スカーレットギフト(Lv75で使用間隔短縮)

- 効果: 敵のCTを1つ吸収し、味方全体の奥義ゲージをUPさせる。
- 数値/スケーリング: 奥義ゲージ+20%UP(基本弱体成功率100%)。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki側の当該部分は未取得)

### アビリティ3: チャームスローブ(Lv45で取得、Lv95で性能強化)

- 効果: 敵に魅了効果を付与し、自分に必ずトリプルアタックを付与する。ヴァンパイアブラッド消費で効果を追加できる。
- 数値/スケーリング: 魅了効果(阻害率約20%、180秒、基本弱体成功率100%)。必ずトリプルアタック(2ターン)。VB消費時追加: ブラッドクイーン効果(消去不可、3ターン、攻撃+50%UP別乗算/久遠枠加算、防御+100%UP、ターン終了時闇属性5倍ダメ上限約56万)。ターン進行時に攻撃行動2回。
- CT(クールタイム): 8ターン(Lv95で6ターンに短縮)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki側の当該部分は未取得)

### 奥義: ブラッディ・アブソープション(最終後)

- 効果: 敵に闇属性ダメージを与え、自身にヴァンパイアブラッドを2つ付与する。対象が魅了状態時は奥義性能もUPする。
- 数値/スケーリング: 倍率5倍。ヴァンパイアブラッド+2。対象魅了時: 奥義ダメ+50%UP/奥義上限+30%UP。
- 出典: GameWith / gbf.wiki(基本ステータス一致で確認)
- ステータス: 基本ステータス一致(奥義詳細はGameWithのみで確認)

### サポートスキル(常時発動)

- セルフィッシュ・ロイヤル: 通常攻撃/奥義時に吸収効果を得る。闇属性キャラが敵HP吸収した回数に応じてターン終了時、タゲに関わらず闇属性ダメージを与える。
- 数値/スケーリング: 吸収効果(最大500)。倍率3倍(上限約21.5万、最大6回)。
- クイーンズチャージII(Lv90で取得): バトル開始時にヴァンパイアブラッド+1(最大2、消去不可)。ヴァンパイアブラッド数に応じて攻撃性能UPと闇属性追撃効果を得る。
- 数値/スケーリング: 攻撃+15%UP×VB数(最大30%、攻刃加算)。DA約+15%/TA約+8~10%UP×VB数(最大約30%/16~20%)。闇属性+10%追撃効果×VB数(最大20%)。
