# 風ランスロット(Lancelot (Wind))

## 概要

奥義で自身に効果時間長めの追撃と、アビリティで味方全体に連撃UP+追撃を付与できるアタッカー。回避成功時の自動多段ダメで火力貢献でき、自動発動可能な2種の累積防御DOWNもあり、フルオート運用の適性が高い。

## スキル構成

### アビリティ1: ブレードインパルス(Lv55で性能強化・短縮)

- 効果: 敵に風属性ダメージを与え、自分に回避率UPと敵対心大幅UPを付与する。
- 数値/スケーリング: 倍率1.0倍×4回(上限約14.75万)。回避率+60%UP。敵対心大幅UP(3ターン、4人パーティ時タゲ率約67%)。
- CT(クールタイム): 6ターン(Lv55で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: トゥルブレンツ(Lv75で性能強化・短縮)

- 効果: 敵全体に風属性ダメージを与え、防御DOWNと風属性防御DOWN(共に累積)を付与する。
- 数値/スケーリング: 倍率1.5倍×3回(上限約13.5万)。防御-10%DOWN(累積最大30%)。風属性防御-10%DOWN(累積最大30%)。共に基本弱体成功率90%。
- CT(クールタイム): 6ターン(Lv75で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: リッターオルデン(Lv45で習得)

- 効果: 味方全体に連続攻撃確率UPと風属性追撃効果を付与する。
- 数値/スケーリング: DA率+30%/TA率+15%UP(3ターン)。風属性追撃+10%(3ターン)。
- CT(クールタイム): 7ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: アイト・フリューゲル

- 効果: 敵に風属性ダメージを与え、DA率DOWNを付与する。自身に風属性追撃効果を付与する。
- 数値/スケーリング: 倍率4.5倍。DA率-50%DOWN(180秒)。風属性追撃+50%(6ターン、奥義ターン含む)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 護国の双剣: 自分の回避率をUPする。回避時にトゥルブレンツ(2アビ)が発動し、3アビの再使用間隔が短縮される。
- 数値/スケーリング: 回避率+15%UP。3アビ再使用間隔-1ターン(回避時)。
- 白竜騎士団団長: 追撃効果付与中、奥義性能をUPする。
- 数値/スケーリング: 奥義ダメ+40%UP。奥義上限+10%UP。
