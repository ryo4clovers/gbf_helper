# エミリア(Amelia)

## 概要

敵特殊技毎に自動発動する回復+クリア付き多段ダメージアビリティで弱体回復と火力を同時に担えるキャラ。土属性キャラ単体に確定トリプルアタック+再行動付与で火力底上げも行えるうえ、強化効果12個以上で2回発動など誘惑のチェインと相性が良く、短期周回から中長期のフルオートで火力・支援役として活躍する。

## スキル構成

### アビリティ1: ファイスソード(Lv55短縮)

- 効果: ターゲットに関わらず敵に土属性ダメージを与える。土属性キャラに活性効果を付与し、弱体効果を1つ回復する。強化効果12個以上時は攻撃回数が2倍になり、ブロック効果も追加される。
- 数値/スケーリング: 倍率1倍(上限約9.3万)×5回(強化12個以上で10回)。活性(500回復、回復しない時奥義ゲージ+10%、3ターン)。ブロック(被ダメージ20%軽減、発動率100%、3ターン、強化12個以上時)。
- CT(クールタイム): 8ターン(Lv55で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: ヴァリアントウィル(Lv75短縮)

- 効果: 土属性キャラにクリティカル確率アップと会心効果を付与する。強化効果12個以上時は水属性ダメージカットも追加される。
- 数値/スケーリング: クリティカル(倍率30%、発動率70%、3ターン)。会心(クリティカル時与ダメージ+5万加算、3ターン)。水属性ダメージ-60%(1ターン、強化12個以上時)。
- CT(クールタイム): 7ターン(Lv75で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: クイック・シバルリィ(Lv45で習得)

- 効果: 土属性キャラ単体のアビリティ再使用間隔を短縮し、ターン進行時に攻撃行動を2回行わせる。強化効果12個以上時は必ずトリプルアタックも追加される。
- 数値/スケーリング: アビ再使用間隔-1ターン。必ずトリプルアタック(1ターン、強化12個以上時)。
- CT(クールタイム): 9ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: ノーブル・シルバー

- 効果: 敵に土属性ダメージを与える。味方全体に土属性攻撃アップとDA率・TA率アップを付与する。
- 数値/スケーリング: 倍率4.5倍。土属性攻撃+15%(4ターン)。DA率+15%/TA率+15%(4ターン)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- エルフォース王都騎士団団長: 一度だけ戦闘不能にならずHP1で耐える。自身の強化効果が12個以上の時、各アビリティが強化される。
- 気高き白銀: 敵特殊技使用時、自身のアビリティ再使用間隔を短縮し、1アビ(ファイスソード)を発動する。
- 数値/スケーリング: アビ再使用間隔-1ターン。
