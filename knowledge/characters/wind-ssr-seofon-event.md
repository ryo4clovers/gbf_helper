# シエテ(アナザー)(Seofon (Event))

## 概要

演算世界における十天衆シエテの可能性の一つとして登場する9周年イベント配布キャラ。装備している剣武器の本数に応じて別枠攻撃UPや連撃率UP、通常攻撃与ダメUPを得る自己強化型のアタッカーで、通常版シエテが奥義軸なのに対しカウンターや通常攻撃軸で火力を発揮する。十天衆総べ称号「十天光輝の楯」の効果対象でもある。

## スキル構成

### アビリティ1: イスピラツィオーネ(Lv55短縮)

- 効果: 自分にカウンター効果と敵対心UPを付与する。
- 数値/スケーリング: 3倍カウンター(被ダメ時、7回、1ターン)。敵対心UP(タゲ率100%、1ターン)。
- CT(クールタイム): 8ターン(Lv55で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ2: インフィニート・クレアーレ(Lv75短縮)

- 効果: ターゲットに関わらず敵に風属性ダメージを与え、自分のHPを回復する。
- 数値/スケーリング: 倍率1.5倍(上限約25万)×10回。HP回復(与ダメ10%分、最大3000)。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ3: フォンテ・ディ・エネルジーア(Lv45で習得、3月11日追加ストーリーで習得)

- 効果: 装備「剣」武器数に応じて自分に風属性追撃効果を付与する。ターン経過なしで通常攻撃を実行する。
- 数値/スケーリング: 風属性追撃+7%×剣武器本数(最大77%、1ターン)。
- CT(クールタイム): 7ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### 奥義: エスパーダ・エストレーヤ

- 効果: 敵に風属性ダメージを与え、自分にガッツ効果(HP25%以上時にHP1で耐える)を付与する。
- 数値/スケーリング: 倍率4.5倍。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### サポートスキル(常時発動)

- 星海剣聖: 通常攻撃の与ダメージをUPする代わりに奥義ゲージ上昇量がDOWNする(デメリット)。
- 数値/スケーリング: 通常攻撃与ダメ+10%UP(天司枠加算)。奥義ゲージ上昇量-30%DOWN。
- 剣拓の煌めき: 装備「剣」武器数に応じて自己強化する(最大7本)。
- 数値/スケーリング: 攻撃+3%UP×本数(最大20%、別枠乗算、久遠・総べ称号枠加算。総べ称号有の場合は攻撃10%分が同枠加算)。防御+10%UP×本数(最大70%)。連続攻撃確率UP(最大DA率100%/TA率50%)。
