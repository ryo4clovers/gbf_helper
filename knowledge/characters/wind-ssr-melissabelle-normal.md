# メリッサベル(Melissabelle)

## 概要

ダメージアビリティをメインに戦うキャラ。2種の多段ダメージアビリティ持ちなので、与ダメ加算とのセット運用や特殊技の解除用など、ヒット数が求められるバトルで活躍できる。「ぱわー」が上がるほど高火力になるため中長期戦を中心に活躍する。バランス調整・最終解放を受けている。

## スキル構成

### アビリティ1: コンティニュウム(Lv55で性能強化・短縮、調整後、最大HP20%消費)

- 効果: 自分に即座に奥義発動可能、ダメージアビリティ即時使用可能、クリティカル確率UPを付与する。
- 数値/スケーリング: クリティカル確率UP(倍率30%/発動70%)。
- CT(クールタイム): 12ターン(Lv55で11ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ2: ライトセイヴィアー++(Lv75短縮、Lv90で性能強化)

- 効果: ターゲットに関わらず敵に風属性ダメージを与える。ぱわーに応じて攻撃回数がUPする。Lv90以降は自分のHP回復と奥義ゲージUPも追加される。
- 数値/スケーリング: 倍率1~1.5倍(上限約8.1万)×5回(ぱわーに応じ最大12回)。Lv90後: HP回復(最大3000)。奥義ゲージ+30%UP。
- CT(クールタイム): 7ターン(Lv75で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ3: レフトセイヴィアー+(Lv45で習得、Lv95で性能強化)

- 効果: ターゲットに関わらず敵に風属性ダメージを与える。ぱわーに応じて攻撃回数がUPする。Lv95以降はカウンター効果も追加される。
- 数値/スケーリング: 倍率1~1.5倍(上限約8.1万)×5回(ぱわーに応じ最大12回)。Lv95後: 2倍カウンター(回避・被ダメ時、3回、3ターン)。
- CT(クールタイム): 6ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### アビリティ4: モイストプロテクション(Lv100で習得)

- 効果: 自分にかばう効果(全体)、被ダメージ軽減、与ダメージ上昇を付与する。
- 数値/スケーリング: 全体かばう(1ターン)。被ダメ80%軽減(1ターン)。与ダメージ上昇(敵最大HP1%分、最大5万、3ターン)。
- CT(クールタイム): 7ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### 奥義: 五月乱髪++(最終後)

- 効果: 敵に風属性ダメージを与え、ぱわー数に応じた追加ダメージを与える。自身のアビリティ再使用間隔を短縮し、ガッツ効果を付与する。
- 数値/スケーリング: 倍率5倍(最終後、通常時は4.5倍)。風属性1.5倍追加ダメ(上限約11.1万)×ぱわー数(最大7回)。全アビリティ再使用間隔-2ターン。ガッツ効果(消費まで永続、最終後追加)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiで4★時点のHP/ATK一致)

### サポートスキル(常時発動、調整後)

- 自動迎撃毛刃: ターン終了時に確率で追加ダメージとHP回復が自動発動する(残りHPが少ないほど発動確率UP)。
- 数値/スケーリング: 倍率1~1.5倍(上限約8.1万)×5回。HP20%回復(最大2000)。発動確率: 最小約30%(HP100%)~最大約100%(HP25%以下)。
- 黄金の艶めき: ダメージアビリティ使用時、ぱわーが上昇する(最大7、消去不可)。ぱわーに応じて攻撃・アビ上限がUPする。
- 数値/スケーリング: 攻撃+5%UP×ぱわー(最大35%、別枠乗算、久遠枠加算)。アビ上限+5%UP×ぱわー(最大35%)。
