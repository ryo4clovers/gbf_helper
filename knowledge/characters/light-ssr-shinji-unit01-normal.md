# シンジ&初号機(Shinji & Unit 01)

## 概要

エヴァンゲリオンコラボキャラ。ストーリークリアで無料入手可能。「シンクロ率」に応じて自己強化が進み、100%到達で奥義が極大化するバランス型アタッカー。

| 項目 | 内容 |

| 種族 | ヒューマン |
| タイプ | バランス |
| 入手方法 | エヴァンゲリオンコラボのストーリー「幕間」クリアで加入 |

## スキル構成

### アビリティ1: 大型高周波ナタ+

- 効果: 敵全体に光属性ダメージを与え、強化効果を1つ無効化する。敵が特殊技を使用した時に自動発動。シンクロ率80%以上で無効化に成功すると他のアビリティが即時使用可能になる。
- 数値/スケーリング: 倍率8倍、ダメージ上限目安 約81万。
- CT(クールタイム): 7ターン。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### アビリティ2: アサルトトライプル+

- 効果: 敵全体にランダムターゲットで光属性ダメージ(6回攻撃)を与え、防御ダウン(累積)を付与する。シンクロ率80%以上で2回発動。
- 数値/スケーリング: 1発あたり倍率1倍、ダメージ上限目安 約6万/発。防御-10%(累積最大30%)×180秒。
- CT(クールタイム): 6ターン。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### アビリティ3: 不退の意思(Lv45で習得)

- 効果: 自身が効果中必ずトリプルアタックになる。発動する度に追加効果(2回目: クリティカル率アップ、3回目: 光属性追撃、4回目: 通常攻撃ダメージ上限アップ)が加算される。
- 数値/スケーリング: 2回目クリティカル率(倍率20%/発動率100%)、3回目光属性追撃50%、4回目通常攻撃ダメージ上限+20%。
- CT(クールタイム): 6ターン。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### 奥義: 荷電粒子砲+

- 効果: 敵単体に光属性ダメージを与え、命中率ダウンを付与。アビリティ3(不退の意思)を即時使用可能にする。シンクロ率100%時は極大ダメージに変化。
- 数値/スケーリング: 通常時 倍率4.5倍/上限168.5万。シンクロ率100%時 倍率12.5倍/上限242万。命中率-50%×3ターン。
- 出典: GameWith, gbf.wiki
- ステータス: 未検証(二次情報だが両サイトで数値一致)

### サポートスキル(常時発動)

- 汎用人型決戦兵器: 最大HP+10%、防御+20%。トリプルアタック時に「シンクロ率」+10%(最大100%、バトル開始時50%)。
- 第3の少年: シンクロ率50%以上から10%ごとに攻撃アップ(最大50%)・防御ダウン(最大50%)・DA率/TA率アップ(最大DA100%/TA50%)・通常攻撃与ダメージアップ(最大20%)が段階的に強化される。シンクロ率100%時は強化効果が無効化されなくなり、ターン終了時に一度だけHP・弱体効果全回復+全アビリティ即時使用可能になる。
