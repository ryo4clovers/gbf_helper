# アルルメイヤ(Arulumaya)

## 概要

いくつかの弱体・支援アビリティを持つ土属性のサポートキャラ。弱体効果を1度無効にする「マウント」が長所で、スロウと合わせ厄介な特殊技を持つ強敵相手に挑む際などに活躍する。最終上限解放後は事象投影による火力支援も強力になる。

## スキル構成

### アビリティ1: 月天(Lv55/Lv100で性能強化・短縮)

- 効果: 敵全体に土属性ダメージを与え、攻撃ダウンと水属性攻撃ダウンを付与する。
- 数値/スケーリング: 倍率7倍(上限84万)。攻撃-10%(累積、最大40%、180秒)。水属性攻撃-20%(180秒)。いずれも基本弱体成功率100%。
- CT(クールタイム): 8ターン(Lv55で7ターン、Lv100で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: タブラ・ラーサ(Lv75/Lv95で性能強化・短縮)

- 効果: 味方全体に弱体効果無効とバリア効果を付与する。
- 数値/スケーリング: 弱体効果無効(1回)。バリア耐久3000。
- CT(クールタイム): 8ターン(Lv95で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: ナクシャトラ(Lv45で習得)

- 効果: 敵に土属性ダメージを与え、スロウ効果を付与する。
- 数値/スケーリング: 倍率2.5~3倍(上限約42.5万)。基本弱体成功率100%。
- CT(クールタイム): 6ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ4: 事象投影(Lv90で習得)

- 効果: 水晶に事象を投影し(1ターン)、次回使用時に投影を解放して土属性キャラにランダムな強化効果を付与する。使用回数に応じて発動する効果が増加する(最大3回、4回目使用で全部発動)。
- 数値/スケーリング: 土属性追撃+30%(3ターン)。DA率+100%/TA率+50%(3ターン)。クリティカル倍率30%(発動100%、3ターン)。ダメ上限+20%(3ターン)。
- CT(クールタイム): 6ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: セレネ・ティモリア(最終上限解放後)

- 効果: 敵に土属性ダメージを与え、味方全体の奥義ゲージをアップする。事象投影(4アビ)を再使用可能にし、月天(1アビ)を発動する。
- 数値/スケーリング: 倍率5倍(上限168.5万)。奥義ゲージ+10%。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 神託: 敵特殊技使用時、味方全体の弱体効果を短縮する。
- 数値/スケーリング: 弱体効果-2ターン。
- 未来幻視: ターン終了時に敵のCTが最大の場合、味方全体に水属性ダメージ軽減を付与する(強化効果として付与)。
- 数値/スケーリング: 水属性ダメ-70%(2ターン)。
