# シス(イベント)(Seox (Event))

## 概要

3ターン間隔のダメアビ+回避時自動発動ダメアビを主体に火力貢献するアビリティアタッカー。単体でも十分有用な火力役だが、回避率UP系アビ持ちとセット運用だとより強みを発揮できる。十天衆を強化する「十天光輝の楯」の効果対象キャラ(称号「十天衆を総べし者」の獲得条件にはならない)。6周年イベント配布キャラ。

## スキル構成

### アビリティ1: 狼哮(Lv55で性能強化、リンクアビで連動)

- 効果: 敵に闇属性ダメージを与え、自分にカウンター効果と狼爪効果(永続・消去不可)を付与する。回避成功時に六爪無斬(2アビ)が発動する(カウンターの回避では発動しない)。狼爪/狼気はどちらか1つのみで、片方発動時にもう片方を上書きする。
- 数値/スケーリング: 倍率6.0倍(上限約73万)。2.0倍カウンター効果(回避・被ダメージ、2回、1ターン)。
- CT(クールタイム): 3ターン(リンクアビで連動)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は十天衆本体版と判断し棄却)

### アビリティ2: 六爪無斬(Lv75で性能強化、リンクアビで連動)

- 効果: タゲに関わらず闇属性ダメージを6回与え、自分のアビダメ上限をUPし、奥義ゲージをUPし、狼気効果(永続・消去不可)を付与する。回避成功時に狼哮(1アビ)が発動する。
- 数値/スケーリング: 倍率1.5倍(1回あたり上限約8万)×6回。アビダメ上限+10%UP(累積最大50%、永続)。奥義ゲージ+15%UP。
- CT(クールタイム): 3ターン(リンクアビで連動)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は十天衆本体版と判断し棄却)

### アビリティ3: 疾門・紫電(Lv45で習得)

- 効果: 自分に必ずトリプルアタック・敵対心UP・回避率UPを付与する。
- 数値/スケーリング: 確定トリプルアタック(1ターン)。敵対心UP(タゲ率約50%、3ターン)。回避率+20%UP(3ターン)。
- CT(クールタイム): 6ターン。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は十天衆本体版と判断し棄却)

### 奥義: 羅睺一穿虚空拳

- 効果: 敵に闇属性ダメージを与え、敵の全ての攻撃を回避する(永続、1回)。狼爪効果または狼気効果時は奥義性能もUPする。
- 数値/スケーリング: 倍率4.5倍。狼爪/狼気効果時: 奥義ダメ+30%UP、奥義上限+10%UP。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は十天衆本体版と判断し棄却)

### サポートスキル(常時発動)

- カルムの神狼: 狼爪効果中、回避成功時に六爪無斬(2アビ)が発動する。狼気効果中、回避成功時に狼哮(1アビ)が発動する(狼爪効果と狼気効果はどちらか1つのみ付与可能)。
