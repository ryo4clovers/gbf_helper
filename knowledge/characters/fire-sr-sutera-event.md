# スーテラ(イベント)(Sutera (Event))

## 概要

イベント『粧して臨めよ花戦』で加入するキャラ。1アビで自身に翡翠紋を付与して通常攻撃や奥義に追加ダメージを発生し、アタッカーとして活躍する性能。また他アビリティで翡翠紋を消費すれば支援や弱体化もこなせる。

## スキル構成

### アビリティ1: 流れ星(Lv45で性能強化・使用間隔短縮)

- 効果: 敵全体に火属性ダメージを与え、自身に翡翠紋を付与する。
- 数値/スケーリング: 倍率未確認、上限約20万（GameWith）。翡翠紋5枚を付与。

### アビリティ2: 春風(Lv65で使用間隔短縮)

- 効果: 2ターンの間、自分の回避率をUPする。翡翠紋を消費すると味方全体の回避率もUPする。
- 数値/スケーリング: 翡翠紋1枚消費。回避率の値は未確認。Wikiでは自身用と全体用が別の回避率強化として重複すると記載。
- CT(クールタイム): 7ターン(Lv65で6ターンに短縮)。
- 出典: [GameWith][gw] / [gbf.wiki][wiki]（2026-10-04再照合。個別の数値出典・差異は本文に記載）
- ステータス: 下書き（二次情報照合済み、数値・枠・実機挙動は要検証）

### アビリティ3: 狙い撃ちII(Lv35で習得)

- 効果: 敵に火属性ダメージを与え、180秒の間、暗闇効果を付与する。翡翠紋を消費すると敵の攻撃DOWNとDA確率DOWNも追加される。
- 数値/スケーリング: 倍率未確認、上限約42万（GameWith）。暗闇180秒。翡翠紋1枚消費時に攻撃DOWN・DA確率DOWNを180秒追加。攻撃DOWNはGameWith10%(片面枠)、神ゲー攻略15%と不一致。DA低下量・各弱体の成功率は未確認。
- CT(クールタイム): 9ターン。
- 出典: [GameWith][gw] / [gbf.wiki][wiki]（2026-10-04再照合。個別の数値出典・差異は本文に記載）
- ステータス: 下書き（二次情報照合済み、数値・枠・実機挙動は要検証）

### 奥義: 吹花擘柳

- 効果: 敵に火属性ダメージを与える。翡翠紋を消費すると追加でアビリティダメージが発生する。
- 数値/スケーリング: 本体3.5倍（Wiki）。翡翠紋1枚消費時に火属性1.5倍のアビリティダメージを追加。追加分の上限はGameWith約48万、Wiki約48.5万で表記差あり。Wikiではアビリティ上限UPの対象で、奥義上限UPの対象外と記載。
- 出典: [GameWith][gw] / [gbf.wiki][wiki]（2026-10-04再照合。個別の数値出典・差異は本文に記載）
- ステータス: 下書き（二次情報照合済み、数値・枠・実機挙動は要検証）

### サポートスキル(常時発動)

- 精励: メーテラがパーティにいる場合にクリティカル確率がUPする。
- 数値/スケーリング: クリティカル確率UP(倍率30%/発動率約30%)。
- 未完たる魔導弓: 翡翠紋を消費して火属性追撃効果を得る。
- 数値/スケーリング: 通常追撃倍率は未確定。GameWith・神ゲー攻略30%、Wiki25%。Wikiでは通常攻撃の連撃数にかかわらず1ターンに翡翠紋1枚を消費すると記載。
- 出典: クリティカルの倍率・発動率は[GameWith][gw]、追撃は[GameWith][gw] / [gbf.wiki][wiki] / [神ゲー攻略][kg]（2026-10-04、要検証）。
