# 風ユグドラシル(Yggdrasil (Wind))

## 概要

高頻度で使える「弱体ターン数短縮付き回復」や、消去不可の「被ダメ軽減」「吸収」「ディスペルガード」等で耐久支援に優れたキャラ。奥義毎や被弾なしのターン終了時にもHP回復が可能で、強敵相手の中長期戦向けフルオートや耐久力が求められる高難易度で活躍する。攻撃力が低いデメリットを持つ。

## スキル構成

### アビリティ1: 創樹の新芽(Lv55短縮)

- 効果: 風属性キャラに強化効果無効化耐性、被ダメージ軽減、吸収効果を付与する(消去不可)。
- 数値/スケーリング: 強化効果が無効化されない。被ダメージ-20%軽減。吸収効果(最大1000)。5ターン。
- CT(クールタイム): 14ターン(Lv55で12ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ2: 始まりのそよ風(Lv75短縮)

- 効果: 風属性キャラの奥義ゲージをUPし、狂風の刻印を付与する。
- 数値/スケーリング: 奥義ゲージ+30%UP。狂風の刻印+1(最大5、消去不可)。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ3: テラ・セラピア(Lv45で習得)

- 効果: 味方全体にHP回復と弱体効果のターン数短縮を付与する。狂風の刻印が5の時は2回発動する。
- 数値/スケーリング: HP20%回復(最大1000)。弱体効果-2ターン短縮(最短1ターンまで、0ターンにはできない)。
- CT(クールタイム): 4ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### 奥義: エアデ・ウアタイル

- 効果: 敵に風属性ダメージを与え、自分に狂風の刻印を付与し、テラ・セラピア(3アビ)を発動する。
- 数値/スケーリング: 倍率4.5倍。狂風の刻印+1(最大5、消去不可)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### サポートスキル(常時発動)

- 小さき芽: 攻撃力DOWN(デメリット)と敵対心DOWNを持つ。ダメージを受けなかった場合、ターン終了時に風キャラにHP回復と奥義ゲージUPを行う。
- 数値/スケーリング: 攻撃力-20%DOWN(デメリット)。敵対心DOWN。ダメージ無し時: HP回復(最大500)。奥義ゲージ+10%UP。
- 創樹の恵愛: 風属性キャラが狂風の刻印数に応じて奥義ゲージ上昇量をUPする(自分がサブメンバーにいる場合でも発動)。
- 数値/スケーリング: 奥義ゲージ上昇量+4%×刻印数(最大20%)。
