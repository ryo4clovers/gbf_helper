# モニカ(リミテッド)(Monika (Grand))

## 概要

自己火力/回復/味方強化/敵弱体の4種のリンクアビリティを状況に応じて使い分け、様々な役割をこなせるキャラ。使用回数に応じて各アビリティが強化されていくので、特にターン数のかかるバトルにおいて真価を発揮する。

## スキル構成

### アビリティ1: 覇旋雷閃(Lv55で性能強化、リンクアビリティ)

- 効果: 敵に風属性ダメージを与え、自分に弱点属性追撃効果を付与する。使用回数に応じて追撃効果の性能がUPする(最大2回)。
- 数値/スケーリング: 倍率5.0倍(上限約63万)。1回目: 弱点属性追撃+40%(3ターン)。2回目: +60%(4ターン)。3回目: +80%(5ターン)。
- CT(クールタイム): 3ターン(リンクアビリティで連動)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ2: エアスト・ヒルフェ(Lv75で性能強化、リンクアビリティ)

- 効果: 味方全体のHPを回復し、弱体効果を1つ回復する。使用回数に応じて回復性能がUPする(最大2回)。
- 数値/スケーリング: HP20%回復。1回目: 最大2000回復。2回目: 最大2500回復。3回目: 最大3000回復。
- CT(クールタイム): 3ターン(リンクアビリティで連動)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ3: 白翼の風(リンクアビリティ)

- 効果: 風属性キャラのクリティカル確率をUPする。使用回数に応じて会心効果やダメージ上限UPが追加される(最大2回)。
- 数値/スケーリング: クリティカル確率UP(倍率30%/発動率約70%、3ターン)。2回目: 会心効果追加(3ターン)。3回目: ダメージ上限+10%UP追加(3ターン)。
- CT(クールタイム): 3ターン(リンクアビリティで連動)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### アビリティ4: 雷瞬閃(Lv45で習得、リンクアビリティ)

- 効果: 敵の強化効果を1つ無効化する。使用回数に応じてスロウや麻痺が追加される(最大2回)。
- 数値/スケーリング: 強化効果1つ無効化。2回目: スロウ効果追加。3回目: 麻痺効果追加(1~2ターン)。
- CT(クールタイム): 3ターン(リンクアビリティで連動)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### 奥義: 旋風雷閃撃鎖斬

- 効果: 敵に風属性ダメージを与え、「紫電の閃き」(追加ダメージ+累積攻防DOWN+奥義ゲージUP)を発動する。
- 数値/スケーリング: 倍率4.5倍。紫電の閃き: 風属性5.0倍ダメージ(上限約63万)。攻防-10%DOWN(累積最大30%、180秒、基本弱体成功率90%)。奥義ゲージ+20%UP。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP一致)

### サポートスキル(常時発動)

- ブリッツシュヴェルト: 回避率をUPし、回避時に「紫電の閃き」を発動する。
- 数値/スケーリング: 回避率+約15%UP。紫電の閃き(回避時): 風属性5.0倍ダメージ(上限約63万)。攻防-10%DOWN(累積最大30%、180秒)。奥義ゲージ+20%UP。
- スカイコマンド: アビリティを使用したターンの間、必ずトリプルアタック、敵対心UP、回避率UPを得る。
- 数値/スケーリング: 必ずトリプルアタック。敵対心UP(4人パーティ時ターゲット率約65~70%)。回避率+約50%UP。
