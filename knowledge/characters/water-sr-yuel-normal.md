# ユエル(SR)(Yuel (Water))

## 概要

味方全体の水属性攻撃UP付与に加えて、クリア+回復を併せ持つキャラ。また自身のDA率も強化できるため、火力を出しつつ味方の支援を担える性能。千年を知る者。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| レアリティ | SR |
| 属性 | 水 |
| 種族 | エルーン |
| タイプ | バランス/楽器・刀 |
| 入手方法 | サイドストーリー『ごめんなさいとありがとう』で加入 |

## スキル構成

### アビリティ1: 燕返し(Lv45でターン短縮)

- 効果: 敵に水属性ダメージを与え、3ターンの間、自分のダブルアタック確率をUPする。
- 数値/スケーリング: ダブルアタック確率35%UP。
- CT(クールタイム): 7ターン(Lv45で6ターンに短縮)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は不一致のため不採用)

### アビリティ2: 水無月(Lv65でターン短縮)

- 効果: 3ターンの間、味方全体の水属性攻撃をUPする。
- 数値/スケーリング: 水属性攻撃15%UP。
- CT(クールタイム): 6ターン(Lv65で5ターンに短縮)。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は不一致のため不採用)

### アビリティ3: 迎暁の儀(Lv35で習得)

- 効果: 味方全体のHPを回復し(最大600)、弱体効果を1つ回復する。
- CT(クールタイム): 8ターン。
- 出典: GameWith
- ステータス: GameWithのみで確認(gbf.wiki候補は不一致のため不採用)

### 奥義: 紅之舞・凛炎

- 効果: 水属性ダメージを与え、回復性能を50%UPする。
- 数値/スケーリング: 倍率(大)。
- 出典: GameWith

### サポートスキル(常時発動)

- 融月: ダブルアタック確率をUPする。
