# メレアガンス(Maleagant)

## 概要

不死身付きの全体かばうや、土属性キャラの20%水属性ダメージカット+防御アップ+ターンダメージ軽減などで味方の耐久面を支援できるキャラ。3アビ中は確定トリプルアタック+逆境に加え、2アビの追撃+ディスペル成功時ターン経過なし攻撃で火力面でも貢献でき、中長期向けフルオートの耐久・ディスペル要員として起用できる。

## スキル構成

### アビリティ1: シルトシュトルム(Lv55短縮)

- 効果: 土属性キャラに防御アップ、水属性ダメージカット、被ダメージの水属性変換、ターンダメージ軽減を付与する。
- 数値/スケーリング: 防御+100%(3ターン)。水属性ダメージ-20%(3ターン)。ターンダメージ-50%(3ターン)。
- CT(クールタイム): 7ターン(Lv55で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: シルバーナーゲル(Lv75短縮)

- 効果: 敵に土属性ダメージを与え、敵の強化効果を1つ無効化する。自身に土属性追撃効果を付与する。無効化に成功した時、ターン経過なしで通常攻撃を実行する。
- 数値/スケーリング: 倍率5倍(上限約73万)。土属性追撃+30%(3ターン)。
- CT(クールタイム): 8ターン(Lv75で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: オプファー・ヘルツシュラッグ(Lv45で習得)

- 効果: 自身の現在HP40%を消費して、自身に全体かばう、逆境効果、必ずトリプルアタック、弱体耐性アップ、強化効果無効化不可、不死身効果を付与する。
- 数値/スケーリング: 逆境(最大90%〜最小30%、3ターン)。弱体耐性+100%(3ターン)。不死身(1回、3ターン)。
- CT(クールタイム): 9ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: アルト・ゲブリュル

- 効果: 敵に土属性ダメージを与える。1アビ(シルトシュトルム)と2アビ(シルバーナーゲル)が即時使用可能になり、3アビ(オプファー・ヘルツシュラッグ)の再使用間隔を短縮する。烈活Lvに応じて土属性追加ダメージを与える(最大4回)。
- 数値/スケーリング: 倍率4.5倍(上限約168.5万)。3アビ再使用間隔-1ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- アヴァロンの憶竜: 奥義ゲージ上昇量がダウンする代わりに、被ダメージ時に全力で3倍カウンター(2回)を得る。
- 数値/スケーリング: 奥義ゲージ上昇量-35%。カウンター倍率3倍(2回)。
- 軌跡を伝える者: 土属性キャラがHPまたは最大HPを消費するアビリティを使用時、自身の「烈活Lv」が1上昇する(最大4)。烈活Lvに応じて攻撃・防御アップ、吸収効果、通常攻撃与ダメージアップ、アヴァロンの憶竜のカウンター回数アップを順に得る。
- 数値/スケーリング: 攻撃+30%(別乗算、久遠枠)。防御+100%。吸収(最大500)。通常攻撃与ダメージ+20%。カウンター回数2回→4回。
