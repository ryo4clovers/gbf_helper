# オイゲン(リミテッド)(Eugen (Grand))

## 概要

優秀な単体奥義支援「アームド効果」や、奥義による味方支援もこなせるキャラ。3ターンで計4連発できる追加ダメ付きの奥義で短いターン内でのダメージ出力に優れており、奥義軸のアタッカーとして起用候補となれる性能。

## スキル構成

### アビリティ1: デトネイト・エイム(Lv55短縮、Lv90で性能強化)

- 効果: 自身にカウンター効果、敵対心UP、クリティカル率UP、会心効果を付与する。
- 数値/スケーリング: カウンター倍率4.0倍(回避、4回、3ターン)。敵対心UP(4人パーティターゲット率約66%)。クリティカル倍率50%(発動100%)。会心効果(敵最大HP1%分、上限5万)。3ターン。
- CT(クールタイム): 7ターン(Lv55で6ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: サドンアタック(Lv75短縮)

- 効果: 土属性キャラ単体に「アームド効果」(消去不可)と高揚効果を付与する。
- 数値/スケーリング: 奥義ダメ+50%/奥義上限+30%/クリティカル倍率50%(発動率100%、5ターン)。高揚(20%、5ターン)。
- CT(クールタイム): 10ターン(Lv75で9ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: オートイグニッション(Lv45で習得、Lv100で性能強化)

- 効果: 自身の奥義ゲージを100%にし、弱体効果を全回復する。ターン終了時に奥義ゲージが再度100%になり(2ターン)、効果終了時に奥義再発動が付与される。
- 数値/スケーリング: 奥義再発動(1回)。
- CT(クールタイム): 12ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ4: 絆の銃(Lv95で習得)

- 効果: 敵に土属性ダメージを与え、自身に「蒼醒弾」を付与する(消去不可)。
- 数値/スケーリング: 倍率10倍(上限約130万)。蒼醒弾+5。
- CT(クールタイム): 10ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: ディー・バンデ・カノーネ(最終上限解放後)

- 効果: 敵に土属性ダメージを与え、味方全体に土属性攻撃UPとDA確率UPを付与する。敵の土属性防御をダウンさせる。
- 数値/スケーリング: 倍率5.0倍。土属性攻撃+30%/DA確率+30%(4ターン、奥義使用ターン含む)。土属性防御-10%(累積、最大30%、180秒、基本弱体成功率100%)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- ツングースカ・バタフライ: 敵のターゲットになった場合、チェインバースト性能をアップする(累積、最大5回、永続)。
- 数値/スケーリング: CBダメ+20%(最大100%)。CB上限+6%(最大30%)。
- デトネイトショット: クリティカル発生時にダメージ上限をアップする。「蒼醒弾」数に応じて奥義時は追加ダメージ、通常時は蒼醒弾消費でダメージを与える。
- 数値/スケーリング: ダメージ上限+10%。奥義時追加ダメ倍率1倍(上限約18万)×蒼醒弾(最大5回、消費なし)。通常時: 蒼醒弾1消費で倍率1.5倍(上限約63万)。
