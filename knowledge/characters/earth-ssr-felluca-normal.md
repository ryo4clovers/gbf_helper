# フェルルカ(Felluca)

## 概要

1アビで付与する3種の特殊弱体を起点に、敵の行動に合わせて自動でダメージや弱体効果が発動し、固有Lv(カフア・レポ・マウナ)を溜めていくのが特徴。溜めたスタックを消費する3アビで、高倍率ダメージや行動阻害に加えて、味方全体に乱撃や通常与ダメージ上昇などで火力を底上げできるので、中長期向けの支援・ディスペル要員として起用できる。

## スキル構成

### アビリティ1: エコル・マウ・マナ(Lv55短縮)

- 効果: 敵全体に3種の弱体(カフフ・アヒ/カフフ・ワイ/カフフ・マカニ、いずれも回復不可、必中)を付与する。敵の行動に応じて各弱体が消費され、追加効果とダメージが発生し、敵に「カフア・レポ・マウナ」が1個付与される(最大6、回復不可)。
- 数値/スケーリング: カフフ・アヒ(敵特殊技時消費、火属性倍率6倍、上限約121.5万、強化効果1つ無効化)。カフフ・ワイ(敵通常攻撃時消費、水属性倍率6倍、上限約121.5万、DA率50%/TA率50%ダウン、2ターン)。カフフ・マカニ(チェインバースト時消費、風属性倍率6倍、上限約121.5万、被ダメージ+3万、3ターン)。
- CT(クールタイム): 6ターン(Lv55で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: パレ・オ・クー(Lv75短縮)

- 効果: 土属性キャラに弱体耐性アップ、強化効果無効化不可、再生効果を付与する。2回目発動以降はブロック効果と被ダメージ軽減も追加される。
- 数値/スケーリング: 弱体耐性+200%(5ターン)。再生(最大1000回復、5ターン)。ブロック(20%軽減、発動率100%、5ターン、2回目以降)。被ダメージ-3000(5ターン、2回目以降)。
- CT(クールタイム): 13ターン(Lv75で12ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: ピィ・ケ・アイナ(Lv45で習得)

- 効果: 敵全体のカフア・レポ・マウナを6個消費して、多段の土属性ダメージと行動封印、CTリセット、強化効果3つ無効化を行う。自身に「女王の檄令」効果(3ターン)を付与し、土属性キャラに乱撃効果とダメージ上限アップ、通常攻撃与ダメージ上昇を付与する。他のアビリティが即時使用可能になる。カフア・レポ・マウナが6個の敵がいる時のみ発動可能。
- 数値/スケーリング: 合計倍率48倍(上限約463.5万、合計12回)。行動封印(1ターン)。乱撃(2ヒット)。ダメージ上限+10%。通常攻撃与ダメージ+最大3万。
- CT(クールタイム): 0ターン(発動条件あり)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: オライ・ケ・アクア

- 効果: 敵に土属性ダメージを与え、弱体耐性ダウンと命中率ダウンを付与する。
- 数値/スケーリング: 倍率4.5倍(上限約168.5万)。弱体耐性-20%(180秒)。命中率-50%(3ターン、奥義使用ターン含む)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 若き女王と猛き神: バトル開始時に自身へバリア効果を付与する。ダメージを受けなかったターン終了時、土属性キャラが必ずトリプルアタックする(1回)。
- 数値/スケーリング: バリア(耐久値6000)。
- 自然を従えし魔術師: 敵の火・水・風属性耐性を無視して弱点をつく。女王の檄令中は土属性キャラに乱撃効果、ダメージ上限アップ、通常攻撃与ダメージ上昇も付与する。
- 数値/スケーリング: ダメージ上限+10%。通常攻撃与ダメージ+最大3万。
- 鳴動する大地: 敵の行動に応じて1アビの各カフフ効果を起動する(敵特殊技時はカフフ・アヒ、敵通常攻撃時はカフフ・ワイ、チェインバースト時はカフフ・マカニ)。起動したカフフ消費で敵にカフア・レポ・マウナを1個付与する(最大6、回復不可)。
