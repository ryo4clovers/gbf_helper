# ランスロット(ハロウィン)(Lancelot (Halloween))

## 概要

1アビでディスペル+多段ダメージ、2アビで弱体対策+高倍率ダメージアビリティ、3アビで完全回避+アビ与ダメージ上昇とアビダメを主軸としたキャラ。被ダメ無しで「黒猫の贈り物」Lvを溜めて火力UPに加え、刻印5時に全消費で10倍ダメージと、フルオート等の中長期向けの編成で火力・ディスペル・弱体対策要員として起用候補となる。

## スキル構成

### アビリティ1: ツァウバーリッター(Lv55短縮)

- 効果: 敵に風属性ダメージを与え、強化効果1つ無効化とDA率・TA率ダウン(累積)を付与する。風属性キャラに「狂風の刻印」を付与する。
- 数値/スケーリング: 倍率1倍(約13万)×5回。DA率-10%/TA率-10%(累積、最大40%)。
- CT(クールタイム): 9ターン(Lv55で8ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: カルト・ハウフ(Lv75短縮)

- 効果: 敵全体に風属性ダメージを与え、風属性キャラに弱体効果無効とディスペルガード効果を付与する。「黒猫の贈り物」Lv5時は攻撃回数が2倍になる。
- 数値/スケーリング: 倍率8倍(上限約80万)。弱体効果無効(1回)。ディスペルガード(1回)。
- CT(クールタイム): 11ターン(Lv75で10ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: レヒエルン・ゲベック

- 効果: 自身が敵の全ての攻撃を回避する(1回)。「レヒエルン・ゲベック効果」(消去不可、被ダメージ3回で解除)を付与する。風属性キャラのアビ与ダメージをアップし、味方が通常攻撃時にランスロットが自動で追加ダメージを与える。
- 数値/スケーリング: 風キャラアビ与ダメ+10%。追加ダメ倍率4.5倍(上限約48万)。
- CT(クールタイム): 12ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: マーギッシュ・ゲシェンク

- 効果: 敵に風属性ダメージを与え、レヒエルン・ゲベック(3アビ)の再使用間隔を短縮する。
- 数値/スケーリング: 倍率4.5倍(上限168.5万)。3アビ再使用間隔-2ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 黒猫の贈り物: 回避率をアップする。自身がダメージを受けなかったターン終了時、1アビが自動発動し、「黒猫の贈り物」Lvがアップする(最大5、消去不可)。Lvに応じて攻防、連続攻撃確率、アビリティ性能がアップする。
- 数値/スケーリング: 回避率+約15%。攻撃+10%×黒猫(最大50%、別枠乗算、久遠枠加算)。防御+20%×黒猫(最大100%)。DA率/TA率UP(最大DA率100%/TA率50%)。アビ倍率+0.1倍加算×黒猫(最大0.5倍)。アビ上限+6%×黒猫(最大30%)。
- どんな悪戯を仕掛けようか!: ターン終了時に「狂風の刻印」5の時、全消費で敵全体に大ダメージを与え、風属性キャラのダメージアビリティ再使用間隔を短縮し、自身が敵の全ての攻撃を回避する。
- 数値/スケーリング: 倍率10倍(上限約116万)。ダメアビ再使用間隔-1ターン。全攻撃回避(1回)。
