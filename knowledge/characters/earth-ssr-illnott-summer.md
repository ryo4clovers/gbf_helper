# 水着イルノート(Illnott (Summer))

## 概要

全体の奥義ゲージ100%消費して4ターン続く「トリプルアタック率100%アップ+追撃30%」「消去不可の攻防50%ダウン」を持ち、AT中などの短期戦で破格の火力支援を行える。2回発動や奥義後自動発動も狙えるスロウ+ディスペルで高難易度適正もあり、短期戦から高難易度まで幅広く活躍できる。

## スキル構成

### アビリティ1: ピース・アウト(Lv55短縮)

- 効果: 敵に土属性ダメージを与え、敵の強化効果を1つ無効化し、スロウ効果を付与する。ピースを1消費すると2回発動する。
- 数値/スケーリング: 倍率5.0倍(上限約73万)。スロウ(基本成功率100%)。
- CT(クールタイム): 9ターン(Lv55で8ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: ロアリング・クルー(Lv75短縮)

- 効果: 味方全体の奥義ゲージを100%消費して、トリプルアタック確率アップ、土属性追撃効果、ショート効果(奥義ゲージが増えない、クリア可)を付与する。
- 数値/スケーリング: TA率+100%(4ターン)。土属性追撃+30%(4ターン)。
- CT(クールタイム): 14ターン(Lv75で12ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: フルーレセント(Lv45で習得)

- 効果: 敵全体に「フルーレセント」効果(延長不可、回復不可、5ターン)を付与する。攻防ダウン、DA率・TA率ダウン、被ダメージ上昇を含む。再使用不可。
- 数値/スケーリング: 攻撃-50%。防御-50%。DA率-100%/TA率-100%。被ダメージ上昇(敵最大HPの1%分、最大3万)。基本弱体成功率200%。
- CT(クールタイム): 記載なし(1戦1回限定)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: Bomb the System

- 効果: 敵に土属性ダメージを与える。ピースを1消費して1アビ(ピース・アウト)を発動する。
- 数値/スケーリング: 倍率4.5倍。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- サマープランク: バトル開始時に自身がバトルメンバーにいる場合、土属性キャラの奥義ゲージをアップする。
- 数値/スケーリング: 奥義ゲージ+40%。
- ナイトプール・グラフィティ: 敵の攻撃行動のターゲットになった場合、自身に「ピース」+1を付与する(最大3)。
