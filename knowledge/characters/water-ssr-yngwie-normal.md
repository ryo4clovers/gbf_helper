# イングヴェイ(Yngwie)

## 概要

バトル前にノーマルスタイル/スタイルシフトを切り替えて耐久重視か攻撃特化かを選択できるキャラ。ノーマルスタイルは「タフガイ」状態中の攻防大幅強化と壁役、10ターン後に使用可能な超高倍率奥義が持ち味。スタイルシフト後は現HP50%消費の自己強化による確定トリプルアタック+追撃と、自動発動ダメージアビリティでの通常火力が強み。

## スキル構成

### アビリティ1(ノーマルスタイル): オール・カミング(Lv55短縮、Lv90・Lv95性能追加)

- 効果: 自身にカウンター効果と敵対心アップを付与する。Lv90強化後は高揚効果、Lv95強化後は被ダメージ回数に応じた奥義ゲージアップも追加される。
- 数値/スケーリング: カウンター倍率2.5倍(被ダメージ、5回、3ターン)。敵対心100%(3ターン)。奥義ゲージ+5%×被ダメージ回数(最大50%、Lv95強化後)。
- CT(クールタイム): 8ターン(Lv55で7ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ1(スタイルシフト時): ディサイプルズ・オブ・ヘル

- 効果: 敵に水属性ダメージを与え、自身の奥義ゲージをアップする。
- 数値/スケーリング: 倍率8倍(上限約73万)。奥義ゲージ+30%。
- CT(クールタイム): 6ターン。
- 出典: GameWith
- ステータス: 未検証(GameWithのみ、gbf.wiki側はノーマルスタイル部分までしか確認していない)

### アビリティ2: ザ・ワイルド(Lv75短縮、両スタイル共通)

- 効果: ターン経過なしで通常攻撃を実行する。
- CT(クールタイム): 4ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3(ノーマルスタイル): ノー・マーシー(Lv45で習得、Lv95性能追加)

- 効果: 自身にクリティカル確率アップと水属性追撃効果を付与する。Lv95強化後、タフガイ状態中は「フルメタル・ビィム」が起動し攻撃後に追加ダメージが発生する。
- 数値/スケーリング: クリティカル(倍率50%、発動率50%、3ターン)。水属性追撃+30%(3ターン)。追加ダメージ倍率2.5倍(上限約48万、Lv95強化後)。
- CT(クールタイム): 6ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3(スタイルシフト時): アイアン・クラッド

- 効果: 自身の現在HPを50%消費し、強化効果(消去不可、7ターン)を付与する。1アビ・2アビが即時使用可能になり、1ターンの間同じダメージアビリティを連続2回使用可能になる。
- 数値/スケーリング: 攻撃+30%(別乗算、久遠枠加算)。ダメージ上限+20%。必ずトリプルアタック。水属性追撃+20%(7ターン)。
- CT(クールタイム): 10ターン。
- 出典: GameWith
- ステータス: 未検証(GameWithのみ、gbf.wiki側はノーマルスタイル部分までしか確認していない)

### アビリティ4(ノーマルスタイル): オデッセイ(Lv100のフェイトエピソードクリアで習得)

- 効果: 自身が即座に奥義発動可能になり、1ターンの間奥義性能をアップする。タフガイ状態中のみ使用可能で、再使用不可。
- 数値/スケーリング: 奥義ダメージ+200%(サポアビと合算)。奥義上限+130%。奥義ダメージ特殊上限+50%。
- CT(クールタイム): 戦闘開始10ターン後から使用可能。
- 出典: GameWith
- ステータス: 未検証(GameWithのみ、gbf.wiki側はノーマルスタイル部分までしか確認していない)

### 奥義(ノーマルスタイル、最終後): レッド・ホット・ガーディアン++(通常時)/フルメタル・キャノン(タフガイ時)

- 効果: 敵に水属性ダメージを与える。通常時は自身の奥義ゲージをアップし、必ずトリプルアタックを付与してタフガイ状態に変化する。タフガイ時は高倍率ダメージを与えてタフガイ状態を解除する。
- 数値/スケーリング: 通常時倍率5.0倍。タフガイ時倍率9.0倍。奥義ゲージ+50%(通常時)。必ずトリプルアタック(奥義使用ターン含む3ターン、通常時)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義(スタイルシフト時、最終後): フルメタル・デストロイ

- 効果: 敵に水属性ダメージを与える。自身にカウンター効果とアビリティ使用間隔短縮を付与する。
- 数値/スケーリング: 倍率5倍。カウンター倍率2倍(回避・被ダメージ、2回、2ターン)。アビ使用間隔-2ターン。
- 出典: GameWith
- ステータス: 未検証(GameWithのみ、gbf.wiki側はノーマルスタイル部分までしか確認していない)

### サポートスキル(常時発動)

- タフガイ(ノーマルスタイル): タフガイ状態中、自身の攻撃・防御・連続攻撃率・奥義ダメージ上限を大幅にアップし、弱体無効・敵対心アップを得る。毎ターン奥義ゲージ40%を消費してタフガイを維持する(足りない場合は解除)。
- 数値/スケーリング: 攻撃+80%(別枠乗算)。防御+300%。必ず連続攻撃。奥義ダメージ上限+70%。
- ボーダーライン(ノーマルスタイル): 自身のHPが少ないほど防御をアップする(HP25%以下で+200%)。
- ネバーガイ(スタイルシフト時): 一度だけ戦闘不能にならずHP1で耐える(消去不可)。瀕死時、1度だけターン終了時に全アビリティが即時使用可能になる(消去不可)。
- ボーダーラインIII(スタイルシフト時): 自身のHPが少ないほど攻撃をアップする(HP10%で+37.8%)。ターン終了時にHP50%以下の場合、1アビが自動発動する。
