# ベルソー(Berceau)

## 概要

自身の強化数に応じて土属性キャラの通常与ダメージアップや、強化を5個以上付与されたターンは通常時に2アビ発動と土属性キャラ強化など、強化付与によって真価を発揮するキャラ。自身でもブロック効果やダメージ上限アップなど攻防支援を行えるなど、中長期向けの編成で支援・ディスペル要員として起用できる。

## スキル構成

### アビリティ1: エール・ド・レトラント(Lv55短縮)

- 効果: 土属性キャラに「庇護の殻翼」効果(消去不可、5ターン)とバリア効果を付与する。庇護の殻翼はブロック効果、活性効果、ターン終了時の弱体効果回復を含む。
- 数値/スケーリング: ブロック(20%軽減、発動率100%)。活性(1000回復、回復しない時奥義ゲージ+10%)。バリア(耐久値1万)。
- CT(クールタイム): 14ターン(Lv55で12ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ2: ル・トネール(Lv75短縮)

- 効果: 敵に土属性ダメージを与え、土属性キャラの攻撃・ダメージ上限・DA率/TA率をアップする(累積)。自身の強化効果数が10個以上の時は2回発動する。
- 数値/スケーリング: 倍率1.5倍(上限約11万)×3回。攻撃+10%(累積、最大40%)。ダメージ上限+2%(累積、最大10%)。
- CT(クールタイム): 6ターン(Lv75で5ターンに短縮)。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### アビリティ3: アンフェルモン(Lv45で習得)

- 効果: 敵全体に土属性ダメージを与え、敵の強化効果を1つ無効化し、特殊技ダメージダウンを付与する。
- 数値/スケーリング: 倍率5倍(上限63.5万)。特殊技ダメージ-20%(4ターン)。
- CT(クールタイム): 7ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### 奥義: アンブラッスマンブラ

- 効果: 敵に土属性ダメージと無属性追加ダメージを与える。自身のアビリティ再使用間隔を短縮する。
- 数値/スケーリング: 倍率4.5倍(上限168.5万)+無属性追加ダメージ99万9999。アビ再使用間隔-1ターン。
- 出典: GameWith、gbf.wiki
- ステータス: 検証済み(GameWithとgbf.wikiでHP/ATK一致)

### サポートスキル(常時発動)

- 抱卵の権能: 自身の強化効果数に応じて土属性キャラの通常攻撃与ダメージをアップする。自分以外の土属性キャラから強化効果5個以上付与されたターンの攻撃開始時、自身に「アラボール」効果を付与する。アラボール効果中は通常攻撃時にル・トネール(2アビ)が発動し、土属性キャラのTA確率アップと土属性追撃効果を得る。
- 数値/スケーリング: 通常攻撃与ダメージ+1%×強化数(最大10%)。土属性追撃+20%(アラボール中)。
- 穏やかなる安息のために: 瀕死状態の味方がいる時、自身の防御を大幅アップし、かばう効果を得る。
- 数値/スケーリング: 防御+100%。
