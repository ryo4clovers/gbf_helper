# レスラー(Wrestler)
![レスラー](https://prd-game-a-granbluefantasy.akamaized.net/assets/img/sp/assets/leader/m/160301_01.jpg)

## 概要

全ジョブ中でも格別に強力なリミットアビリティ『ツープラトン』(ターン経過なしで味方全体が通常攻撃を実行)を主軸に、短〜中期戦で短時間で破格の火力を叩き出せる攻撃特化ジョブ。黒麒麟(奥義発動でリミアビ使用間隔をリセットする召喚石)との相性が非常に良く、攻撃大幅UPや確定TAを持つキャラを繰り返し通常攻撃させる運用が強力。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| クラス/系列 | ClassIV / グラップラー系列 |
| 得意武器 | 格闘/格闘 |
| 習得条件 | 特殊条件(詳細はGameWith記事参照) |
| ジョブLvアップボーナス | 攻撃力+2000(Lv1・10習得合計)/HP+300(Lv5・15習得合計)/DA確率20%UP(Lv20習得)/TA確率10%UP(Lv20習得) |
| コンプリートボーナス | 攻撃力+1%、HP+1% |

## アビリティ構成

### アビリティ1: ナイフハンド・ストライク
![ナイフハンド・ストライク](https://prd-game-a-granbluefantasy.akamaized.net/assets/img/sp/ui/icon/ability/m/23_1.png)

- 効果: 自身に3.5倍カウンター(被ダメ/3回)×2ターン、防御30%UP×2ターン、敵対心UP(100%ではない)×2ターン。
- 数値/スケーリング: マスターレベル30強化後は敵対心が100%(疑似かばう)になり、逆境効果(最小30%〜最大90%)×2ターンが追加される。
- CT(クールタイム): 5ターン。
- 出典: GameWith

## リミットアビリティ

### ファイティングスピリット
![ファイティングスピリット](https://prd-game-a-granbluefantasy.akamaized.net/assets/img/sp/ui/icon/ability/m/85_3.png)

- 効果: 自分にファイティングスピリット状態(毎ターンテンションが上昇、被ダメージで解除、最大テンションLv4まで上昇しその後は効果時間のみ延長)を付与する。
- CT(クールタイム): 8ターン。
- 出典: GameWith

### マイクパフォーマンス
![マイクパフォーマンス](https://prd-game-a-granbluefantasy.akamaized.net/assets/img/sp/ui/icon/ability/m/301_3.png)

- 効果: 3ターンの間、参戦者に高揚効果(10%)を付与する。
- CT(クールタイム): 8ターン。
- 出典: GameWith

### ツープラトン
![ツープラトン](https://prd-game-a-granbluefantasy.akamaized.net/assets/img/sp/ui/icon/ability/m/302_1.png)

- 効果: 味方全体がターン経過なしで通常攻撃を実行する。オーガ(下位ジョブ)で習得。
- CT(クールタイム): 15ターン。
- 出典: GameWith

### 練気

- 効果: 5ターンの間、自分の攻撃をUPする(累積)。
- CT(クールタイム): 2ターン。
- 出典: GameWith

### 一字構え

- 効果: 1ターンの間、自身に敵対心を付与する。カウンターが発動している時、カウンター回数が2回追加される。
- CT(クールタイム): 7ターン。
- 出典: GameWith

## サポートスキル(常時発動)

- 受けの美学: 攻撃UP。一度だけ戦闘不能にならずHP1で耐える。
- 武神の極意: 羅喉/阿修羅陣の奥義ゲージ上昇量UP、ターン短縮。
- ストロングスタイル(マスターレベル20で習得): 強化効果が無効化されない。

## マスターレベル強化

- 新サポートアビリティ(Lv20): ストロングスタイル(強化効果が無効化されない)。
- 固有アビリティ強化(Lv30): アビリティ1(ナイフハンド・ストライク)が強化される。
- ステータス強化(合計値): 攻撃力+4000、HP+600、DA率+30%、TA率+6%。

## 極致の証

- ステータス強化内容(1〜6段階): 1段階攻撃力+3500、2段階HP+1500、3段階弱体成功率+7%、4段階奥義ダメ+7%、5段階CBダメ+7%、6段階奥義ダメ上限+5%。
- 追加リミットアビリティ: タッグチーム — 自分の次に配置されたキャラとタッグを組み(消去不可)、毎ターン奥義ゲージ15%UP、ターン終了時に奥義性能UP(累積)、5ターン毎に奥義即時発動可能/奥義が追加発動。使用間隔1ターン(再使用でタッグ解散)。
  - ファイティングソング — 自分にファイティングソング(永続・消去不可)を付与。トリプルアタック確率50%UP、トリプルアタック時にエキサイトマッチLv上昇、Lv7到達でリセットして強力な追加効果発動。再使用不可。
  - ヒール・タイム — 自分を「ヒールに転向」させ、被ダメ時カウンター・通常攻撃後の追加ダメージ・敵特殊技への反撃・奥義ゲージ100%時の即時発動可能などの複合効果を得る。バトル開始時に自動発動、アビリティ使用不可・再使用不可。
