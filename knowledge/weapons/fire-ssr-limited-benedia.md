# ベネディーア(Benedia)
![ベネディーア](https://prd-game-a-granbluefantasy.akamaized.net/assets/img_low/sp/assets/weapon/m/1040502500.jpg)

## 概要

火属性のリミテッドシリーズ(Grand)の銃。通常攻刃(特大)に加え、最終上限解放で「克己」(DA/クリティカル)が付く火グリッドの主力候補。覚醒タイプを選べるほか、ガンスリンガー/ソルジャーでメイン装備すればバレットも活用できる。

## 奥義(チャージアタック)

- 名称: ナバルストライク＋＋(最終上限解放後の形。無印 → ＋ → ＋＋ と進化)

## バレット(銃のみ)

- バレットスロット数: 6(`bullet_info.set_bullets.max_set_count`)
- スロット種別: `[2, 3, 2, 2, 3, 4]`(bullet_1〜6 の `slot_type`。スロットごとにセット可能なバレット種が制限される)
- 補足: 実効はガンスリンガー / ソルジャーのメイン武器時のみ。バレット個別のデータは未整備(bullets カテゴリなし)。gbf.wiki は「No bullet system」と記載しているが、実機レスポンスでは6スロット全て `can_set_flag` = true。gbf 側の記述は「専用バレット武器ではない」意味と思われる。

## 上限解放・強化要素

- 上限解放: 4凸まで。Lv120 で攻刃II→III、Lv150(最終)で克己が解放、奥義が ＋→＋＋ に進化。
- スキルレベル: 上限15(`master.max_weapon_skill_level`)。
- 超越: 非対応。
- オーディアント/AUG: `limit` / `augment_skill` ともに空。
- `master.bonus_level` = "40"(セラフィックの "30" と異なる。+上限またはエレメント関連の可能性、要確認)。

## 編成での役割

- 使用グリッド: 火属性グリッドの通常武器枠(火オメガ / 火神石 どちらでも)。通常攻刃 + 克己で火力と安定性(DA/クリ)を両立。
- メイン装備時の恩恵: 奥義「ナバルストライク＋＋」の全体攻撃UP/アビダメUP。ガンスリンガー/ソルジャー時はバレット。
- 使い分け: 同じ火リミテッド銃・火通常攻刃武器との本数調整。
