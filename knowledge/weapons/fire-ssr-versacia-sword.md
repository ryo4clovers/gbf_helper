# 万象尽滅の宝剣(Versacia Sword (Fire))
![万象尽滅の宝剣](https://prd-game-a-granbluefantasy.akamaized.net/assets/img_low/sp/assets/weapon/m/1040028900.jpg)

## 概要

火属性の破壊の標(ヴェルサシア武器)の剣。第1・第2スキルは固定で「攻刃(特大)+破壊属性追撃」「最大HP(特大)+破壊属性奥義追撃」、第3スキルはアンクレットで**通常攻撃 / 奥義 / アビリティ**のいずれか強化型に変更できる。編成に1本のみ。スキルレベリングは無く効果は固定値。

### スキル3: 闘争の神撃II

- skill_id: `2656`
- 解放レベル: 武器Lv1(表示上)
- 選択式: **はい**(アンクレットで変更。3種: 通常攻撃強化 / 奥義強化 / アビリティ強化)
  - 現在の選択 = **通常攻撃強化型「闘争の神撃」**(奥義強化型・アビリティ強化型は別の神撃スキル)
- 系統/カテゴリ: 通常攻撃ダメージ上限 + 通常攻撃与ダメージ上昇 + 有利属性与ダメージUP + 不利属性ダメージ軽減
- 枠(frame): 通常攻撃ダメージ上限枠 / 与ダメージ上昇枠 / 有利属性与ダメージ枠(要検証)
- 効果: 火属性キャラの通常攻撃ダメージ上限UP/通常攻撃の与ダメージ上昇/有利な属性の敵に対して与ダメージUP/風属性ダメージ軽減
- スキルレベル別の数値: 固定値。GameWith によると「攻刃効果量合計280%以上」条件で有利属性与ダメUP・軽減が各30%。他の値は**要検証**
- **発動条件**: `◆` 以降 — スキル「機炎方陣」または「終炎禁呪」または「火」「業火」「紅蓮」の効果上昇量が**合計280%以上**で発動(= グリッドの火攻刃/方陣攻刃の合計が一定以上)
- 出典: 実機レスポンス / GameWith
- ステータス: 未検証

## 上限解放・強化要素

- 上限解放: 5段階(`max_evolution_level` = 5)。Lv200 が最終(`message`: 「特殊な最終上限解放のため育成アイテムは使用できません」)。
- スキルレベル: **無し**(`max_weapon_skill_level` = 1、効果固定)。`can_skillplus` = true だが効果は不明。
- 第3スキルの変更: アンクレット(通常攻撃 / 奥義 / アビリティ の3型)。
- **装備制限**: `limit.display_comment` =「[破壊の標]の武器は編成にひとつだけ装備が可能です。」(属性ごとに1本)
- 覚醒 / 超越 / オーディアント / AUG: いずれも非対応。

## 編成での役割

- 使用グリッド: 火属性グリッドの通常枠(1本のみ)。第1スキルの攻刃 + 破壊属性追撃 + 神守のHP、第3スキルで通常攻撃/奥義/アビのどれかを伸ばす。
- 発動条件付きの第3スキル(攻刃合計280%以上)があるため、グリッドが十分に育っている前提の武器。
- メイン装備時の恩恵: 奥義「黄泉＋＋」(火ダメージ + ディスペル + 火属性追撃)。
