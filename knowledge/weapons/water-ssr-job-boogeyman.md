# ルクス・イン・デネブリス(Lux in Tenebris)
![ルクス・イン・デネブリス](https://prd-game-a-granbluefantasy.akamaized.net/assets/img_low/sp/assets/weapon/m/1040517500.jpg)

## 概要

ClassV ジョブ「[ブギーマン](../jobs/class5-boogeyman.md)」専用の英雄武器(gbf.wiki『Class Champion Weapons』)。銃。第1〜3スキルすべてがブギーマンのジョブアビリティ(修験…ではなく「血の誓印」「コンチネンタル・テーラー」「セイスヘイヴン」)を強化する固定スキルで、**変更枠は持たない**。代わりに ClassV 英雄武器の特徴として**覚醒(アローサル)枠**を持ち、覚醒Lv15 で固有スキル「闇冥の復讐者」を習得する。作成後も属性を変更できる(`master.change_attribute` = "1")。

## ジョブ専用武器(英雄武器)

- 対応: あり(`job_weapon` = true)
- 対象ジョブ: ブギーマン(`job_weapon_category` = `[]` 空。`unique_weapon[].image` の接頭 `170401` がジョブ `job_id` → [class5-boogeyman.md](../jobs/class5-boogeyman.md))
- 真の姿 / 特殊形態: 「ブギーマン」(`unique_weapon` = `[{ name: "ブギーマン", image: "170401_bw_1_01" }]`)
- 属性選択: 作成時に選択、**作成後も変更可**(`master.change_attribute` = "1")
- 変更枠: なし(第1〜3スキルすべて固定。Chrysaor のようなエンブレム/資質枠は持たない)
- ジョブ側との連動: skill1〜3 がブギーマンの「血の誓印」「コンチネンタル・テーラー」「セイスヘイヴン」を強化

## 覚醒(アローサル)

- 対応: あり(`param.arousal.is_arousal_weapon` = true)
- 最大Lv: **15**(`arousal.max_level` = 15)
- 解放条件: 武器Lv200(`arousal.release_conditions` = `[{ condition_type: "1", condition_value: "200", is_cleared: true }]`)
- 現在の取得状況(この個体): タイプ「攻撃」(`form` = 1)Lv15(コンプリート)

### 覚醒タイプ「攻撃」の内訳(`arousal.total_bonus`)

| 覚醒Lv | 追加内容 |
| --- | --- |
| 2〜7 | 攻刃 +2%(各Lv) |
| 8〜13 | 攻刃 +3%(各Lv) |
| 14 | 攻刃 +5% |
| 15 | 固有スキル「闇冥の復讐者」習得 |

- Lv15 到達時の累積(`total_acquired_bonus`): **攻刃 +35%**(`status_id` 42、`unit_type` 1)+ 「闇冥の復讐者」習得(`status_id` 51、`unit_type` 3)
- 覚醒スキル(`arousal.skill`):
  - `skill_id` 1883「攻刃」— 味方全体の攻撃力上昇 +35%(image `ex_skill_atk`。**覚醒〈EX系〉枠**、通常/方陣攻刃とは別枠、要検証)
  - `skill_id` 2591「闇冥の復讐者」— 「バトル開始時に闇の名声が1上昇/レイン・オブ・パラベラム使用時、自分に自属性追撃効果 ◆メイン装備時/主人公のみ」(`acquired_awakening_level` = 15)
- 他の覚醒タイプ(防御 / 連撃 / 回復 等)の内訳と、それぞれの Lv15 固有スキルが同じか別かは**要検証**(レスポンスは選択中タイプのみ返す)

- 効果(実機 comment): 水属性ダメージ(特大)/自分のアビリティ性能UP ◆闇の名声の数に応じて自属性追加ダメージ(最大5回)
- 数値/スケーリング: 奥義倍率、アビリティ性能UPの内容・値、追加ダメージ1回あたりは**要検証**

- 出典: 実機レスポンス
- ステータス: 未検証

## 上限解放・強化要素

- 上限解放: 5段階。最終上限解放は特殊(育成アイテム不可、ジョブトレジャー等で行う)。
- スキルレベル: 固定(上限1)。
- 覚醒: 上記セクション参照(Lv15、武器Lv200 で解放)。
- 超越 / オーディアント: 非対応。
- `is_group` = "29"(意味は要検証)。

## 編成での役割

- 使用グリッド: グリッド外(主人公メイン武器)。ブギーマンをメインジョブにする時のコア装備。
- メイン装備時の恩恵: 奥義「ヴェンジェンス・ローゼズ＋」+ ジョブアビリティ3種の強化 + 覚醒「攻撃」の味方全体攻刃 +35% + 「闇冥の復讐者」。
- 使い分け: ブギーマン運用ではほぼ必須。覚醒タイプはパーティ需要で選択。
