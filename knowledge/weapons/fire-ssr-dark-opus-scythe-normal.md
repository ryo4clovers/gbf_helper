## 概要

火属性の終末の神器(斧)の**通常攻刃版**。終末の神器は第1スキルの攻刃種別で「通常版」と「方陣(マグナ)版」に分かれ、この「絶対否定の大鎌」は第1スキル「紅蓮の神醒」= **通常攻刃**(神石グリッド向け)。方陣版は [fire-ssr-dark-opus-scythe-magna.md](./fire-ssr-dark-opus-scythe-magna.md)(永遠拒絶の大鎌)。第2・第3スキルはゴーフ・キーでプレイヤーが選択する。終末の神器は編成に1本まで(通常版・方陣版あわせて)。ドラゴニックウェポンとは相互排他ではなく併用可([team-building-basics.md](../mechanics/team-building-basics.md))。

## 武器スキル

### スキル1: 紅蓮の神醒(通常版)

- skill_id: `2192`
- 解放レベル: 武器Lv230(それ以前は「紅蓮の攻刃/神威」系。神醒への強化は超越帯)
- 選択式: いいえ(固定。ただし通常版/方陣版は武器そのものが別 → [方陣版](./fire-ssr-dark-opus-scythe-magna.md)の skill_id は `2198`「機炎方陣・神醒III」)
- 系統/カテゴリ: 神醒(**通常攻刃** + 守護 + 与ダメージ上昇 の複合)
- 枠(frame): 攻刃部分 = **通常攻刃枠**(神石グリッドで乗る) / 与ダメージ上昇部分 = 与ダメージ上昇枠(要検証)
- 効果: 火属性キャラの攻撃力と最大HPが上昇(大)/与ダメージUP(大)
- スキルレベル別の数値: スキルLv25 時の各値は**要検証**
- 発動条件: 常時(火属性キャラ)
- 出典: 実機レスポンス / gbf.wiki
- ステータス: 未検証

### スキル2: ベータ・リベレイション・アルブスII

- skill_id: `2209`
- 解放レベル: 武器Lv1(第2スキル枠自体は最初から。選択肢はゴーフ・キーで変更)
- 選択式: **はい**(ゴーフ・キー〈第2スキル / Soulless Passage 枠〉)
  - 選択肢: α = 通常攻撃ダメージ上限UP / **β = アビリティダメージ上限UP + アビリティ命中率UP(現在の選択)** / γ = 奥義ダメージ上限UP / Δ = チェインバーストダメージ上限UP(gbf.wiki。各50%〈αのみ10%〉、要検証)
- 系統/カテゴリ: アビリティダメージ上限 + アビリティ命中率(β)
- 枠(frame): アビリティダメージ上限枠(通常のダメージ上限とは別。要検証)
- 効果: アビリティのダメージ上限上昇/アビリティ命中確率上昇
- スキルレベル別の数値: β のアビダメ上限UP%(gbf.wiki 目安 50%)は**要検証**
- 発動条件: 常時
- 出典: 実機レスポンス / gbf.wiki(Gauph Key β)
- ステータス: 未検証

### スキル3: 紅蓮の渾身

- skill_id: `502`
- 解放レベル: 武器Lv1(表示上。第3スキル枠は5凸/Lv200帯で解放、選択はゴーフ・キー)
- 選択式: **はい**(ゴーフ・キー〈第3スキル枠〉)
  - 選択肢: 渾身 / 背水 / 技巧 / 連撃 / 進境 / 味方全体ダメージ上限 / 回復上限 / 有利属性ダメージ / 奥義ゲージ上昇 等(gbf.wiki の Ena/Dio/Tria/Tessera 系を含む。**現在の選択 = 渾身**)。完全な選択肢一覧は要検証
- 系統/カテゴリ: 渾身(HPが高いほど攻撃力UP)
- 枠(frame): 渾身枠(HP割合スケール。他の攻刃枠とは別の乗算。要検証)
- 効果: 火属性キャラのHPが多いほど攻撃力が上昇(大)
- スキルレベル別の数値: 渾身(大)スキルLv15 時の値は**要検証**
- 発動条件: 自パーティのHP割合(高いほど強い)
- 出典: 実機レスポンス / gbf.wiki
- ステータス: 未検証

## 奥義(チャージアタック)

- 名称: アポカリプス・アーク・イグナイト＋
- 効果: 火属性ダメージ(極大)/味方全体に業火の刻印を付与/攻防UP(累積)/スキルに応じた追加効果
- 数値/スケーリング: 奥義倍率、攻防UP(累積)の値、刻印の効果は**要検証**
- 進化段階: 上限解放/超越で `＋` が付く(数値・追加効果が強化)
- 選択スキル連動: 「スキルに応じた追加効果」= 第2スキルのゴーフ・キー選択(α/β/γ/Δ)によって奥義の追加効果が変わる
- 出典: 実機レスポンス
- ステータス: 未検証

## 超越(トランセンデンス)

- 対応: あり(`transcendence_pu_flag` = true、`master.max_evolution_level` = 6)
- 最大レベル: 250
- 段階: Lv150(4凸)→ Lv200(第3スキル解放・神醒化)→ 超越で Lv200→250(5段階、各スキルの数値強化・奥義に＋)
- 現在の取得状況(提供インスタンス): Lv250 / evolution 6 / phase 5(超越完了)
- `master.awakening_phase` = "1,5"(上限解放フェーズのマーカー)

## 上限解放・強化要素

- 上限解放: 6段階(4凸まで通常、Lv200・Lv250 は特殊。`message` に「特殊な最終上限解放のため下記を除く育成アイテムは使用不可」)。
- スキルレベル: 第1・第2スキルは上限25、第3スキルは上限15(`max_weapon_skill_level` = 25 / `max_weapon_skill_level_2` = 15)。`can_skillplus` = true。
- **装備制限**: `limit.display_comment` =「[終末の神器]と[ドラゴニックウェポン]の武器は、いずれかひとつだけ装備が可能です。」。**実際は終末の神器が編成に1本まで**(通常版「絶対否定の大鎌」と方陣版「永遠拒絶の大鎌」あわせて)。ドラゴニックウェポンとは併用可(display_comment の文言に反する。[team-building-basics.md](../mechanics/team-building-basics.md) 参照、ユーザー確認 2026-09-07)。
- 覚醒: 非対応(`param.arousal.is_arousal_weapon` = false)。
- オーディアント/AUG: なし。

## 編成での役割

- 使用グリッド: 火属性グリッドの汎用枠(火オメガ / 火神石 どちらでも)。終末の神器は編成に1本のみ。
- メイン装備時の恩恵: 奥義「アポカリプス・アーク・イグナイト＋」(全体刻印 + 累積攻防UP + 選択スキル連動効果)。
- 使い分け: 第2スキル(α/β/γ/Δ)と第3スキルをパーティの火力タイプ(通常/アビ/奥義/CB、渾身/背水)に合わせて選択。
