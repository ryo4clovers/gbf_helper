## ステータス凡例

- 未着手: ファイルとタイトルのみ作成済み
- 下書き: 内容を記入中。未検証値または二次情報を含む
- 検証済み: 記載内容を公式情報または実際のゲーム内挙動で確認済み

## 運用ルール

- 原則として「1開催・1ボス = 1ファイル」とする。
- ファイル名とfrontmatterの`id`は一致させる。
- 実機レスポンス、実際に観測した戦闘挙動、公式情報、二次情報を区別する。
- ローカルのNetwork Recorder書き出しはリポジトリへコピーせず、抽出した非アカウント情報だけを記録する。
- レスポンスに定義が存在しても実戦で発動を観測していない効果は、その旨を明記する。
- 二次情報だけで確認した防御値、倍率、持続時間などは、個別に「未検証」と示す。
