# アビリティ・EXアビリティ・奥義効果

> ステータス: 下書き
> 最終更新: 2026-09-07
> 出典: 実機(グランブルーファンタジー公式サイト、ジョブリスト→ジョブステータスの画面、およびアビリティ選択画面の候補一覧レスポンス`/party_ability_subaction/`、ユーザーの実機操作+提供データによる、2026-09-06〜2026-09-07)。GameWith/gbf.wikiでのクロスチェックは未実施。

## 概要

主人公(グラン/ジータ)のアビリティ枠は、**アビリティ枠の総数自体がジョブの「クラス」によって異なる**(ClassIのみ3枠、それ以外は4枠)。総枠数のうち一部がジョブ固定の基本アビリティ、残りがユーザーの自由選択枠という構造になっている。クラスは大きく2パターンに分かれる: 基本アビリティが多め(2〜3枠)で自由選択枠が1つだけのクラス(ClassI〜III、エクストラ)と、基本アビリティが1枠のみで自由選択枠が3つ(EX/リミット/ベースそれぞれ2つまで)のクラス(ClassIV・V・エクストラII・オリジン)。全クラスの内訳は2026-09-06にユーザー提供情報で確認済み(下記テーブル参照)。

## 詳細

### 枠構成

- **アビリティの最大枠数はクラスによって異なる**(確認済み: ClassIは3枠、オリジン/ClassV/エクストラ〈Ex1〉は4枠。2026-09-06、ユーザー確認)。
- そのうち **ジョブごとに固定の「基本アビリティ」**(ジョブを選んだ時点で自動的に入っており、外せない)が一定数を占める。
- 残りが **自由選択枠**。以下の中から任意に選んでセットできる(選択できる候補が実際に存在するかはジョブによる。例: ベースアビリティの習得元となる下位ジョブが無いジョブでは、ベースアビリティの選択肢自体が無い)。**アビリティ選択UI自体は、EX・リミット・ベースの3種の絞り込み(フィルタ)がクラスに関わらず共通で用意されており、「その枠が無い」のではなく「絞り込んでも候補が0件になる」ジョブの方が多い、という構造(ユーザー確認、2026-09-06)**。ゲーム内HELP(id=12「上位ジョブ」)がClass.IV/Vの説明でベースアビリティに触れていないのも、UI上の枠が存在しないからではなく、候補を持つジョブが少数派だからと考えられる([job-master-level-kyokuchi.md](./job-master-level-kyokuchi.md)参照):
  - **EXアビリティ** — 他ジョブでも使い回せる汎用アビリティ(習得済みのものから選択)。
  - **リミットアビリティ** — 現在のジョブ専用の追加アビリティ([knowledge/jobs/](../jobs/README.md)各ファイルの「リミットアビリティ」節に対応)。**習得ルートは1種類ではない(2026-09-06、[limit-bonus.md](./limit-bonus.md)で判明)**: ジョブLv詳細レスポンスの`limit_ability`配列に具体的な`level`値がある場合はジョブLv到達で自動習得だが、`level`が空文字のもの(大半のジョブがこちらに該当)は**Limit Bonus(内部名`zenith`)経由でLB/ジェムを消費して習得する**必要がある。さらに極致の証(段階6到達)で追加習得できる第3の枠のリミットアビリティも別途存在する([job-master-level-kyokuchi.md](./job-master-level-kyokuchi.md)参照)。
  - **ベースアビリティ** — EXアビリティではない、ジョブ**系列**ごとの専用アビリティ。同系列のエクストラ(Ex1)ジョブのジョブLvを上げることで習得し、一度習得すると同系列の**上位ジョブ**でも使用できるようになる(ユーザー確認、2026-09-06)。**具体例で確認済み**: Ex1ジョブ「アサシン」がジョブLv15で習得する基本アビリティ「ダブルアサシン」([ex1-assassin.md](../jobs/ex1-assassin.md)参照)が、同系列の上位Ex2ジョブ「トーメンター」([ex2-tormentor.md](../jobs/ex2-tormentor.md))の自由選択枠でベースアビリティとして選択可能であることを、Network Recorder拡張機能([tools/network-recorder/](../../tools/network-recorder/))で捕捉したトーメンターの候補一覧レスポンスで確認した。**同種の仕組みがリミットアビリティにも及ぶことを確認(2026-09-06)**: ClassIVの「レスラー」(グラップラー系列)自身のジョブLv詳細レスポンスの`limit_ability`は3つ(ファイティングスピリット/マイクパフォーマンス/ツープラトン)のみだが、GameWithで確認されている選択可能なリミットアビリティは5つで、残り2つ(練気/一字構え)は同系列の下位ClassIIIジョブ「オーガ」自身の`limit_ability`と完全一致する([class4-wrestler.md](../jobs/class4-wrestler.md)・[class3-ogre.md](../jobs/class3-ogre.md)参照)。つまり「ベースアビリティ」的な下位ジョブからの引き継ぎは、Ex1の基本アビリティに限らず、同系列の下位ジョブのリミットアビリティにも適用されると考えられる。なお、旧来「レスラーのリミットアビリティ『ツープラトン』が『オーガ(下位ジョブ)で習得』」という理解を記載していたが、これは誤りで、**ツープラトンはレスラー自身の`limit_ability`に含まれており、オーガ由来なのは練気/一字構えの方**だった(訂正、2026-09-06)。

- 「上限」は自由選択枠の総数を超えない範囲でのみ有効(例: ClassIVで自由選択枠が3の時、EXを2つ入れたらリミット+ベースは合計残り1つまで)。
- **クラスは大きく2パターンに分かれる**: (1)ClassI〜III・Ex1は基本アビリティが多め(2〜3枠)で自由選択枠が1つだけ、(2)ClassIV・V・Ex2は基本アビリティが1枠のみで自由選択枠が3つ、EX/リミット/ベースそれぞれ2つまで(合計3)。**オリジンだけ(2)の変形で、リミット上限がEXより多い(2/3)非対称パターン**。
- 自由選択枠が1つのクラス(ClassI〜III、Ex1)では、EX/リミット/ベースそれぞれの個別上限を確認する意味が薄い(そもそも1つしか選べない)。ただし実際に選択肢が存在するかはジョブごとに異なる。**訂正(2026-09-07)**: 「ナイトの例ではリミット・ベースの選択肢自体が無かった」という以前の記載は誤り。下記「自由選択枠の候補一覧を実データで確認」の通り、ClassIジョブの自由選択枠にも同系列上位のリミットアビリティが多数候補として並ぶ。

### 自由選択枠の候補一覧を実データで確認(全77ジョブ、2026-09-07)

ユーザーが実機で、取得可能な**全77ジョブ**の**アビリティ選択画面の候補一覧レスポンス**(エンドポイント`/party_ability_subaction/all/...`、Network Recorderで捕捉)を取得(2026-09-06にClassI 7+オリジン3、2026-09-07にClassII〜V・エクストラ・エクストラII 67ジョブ)。ページ送り形式(10件/ページ、7〜8ページ)で、全ページ連結すると1ジョブあたり61〜73件の候補。生データは[tools/network-recorder/captures/ability-subaction/{slug}/page-*.json](../../tools/network-recorder/captures/)(git管理外)、名寄せ済みの構造化データは[knowledge/abilities/free-slot-candidates.json](../abilities/free-slot-candidates.json)。

**種別は各エントリの`kind`フィールドで判別する(ユーザー提供の対応表、全77ジョブで整合を確認)**:

| `kind` | 種別 | 補足 |
| --- | --- | --- |
| 1〜4 | **EXアビリティ**(1=ダメージ / 2=強化 / 3=弱体 / 4=回復) | `level`が数値(=そのジョブをそのLvまで上げると習得できる) |
| 5 | **リミットアビリティ** | `level`は空。**極致の証(段階6)で習得するアビリティもkind=5(リミットアビリティ扱い)** |
| 6 | **ベースアビリティ** | エクストラIIジョブのみ候補を持つ(下記) |

**枠上限**(`max_ex`/`max_base`/`max_zenith_ability_count`): オリジン以外の全ジョブで **2/2/2**、オリジンのみ **2/2/3**。

#### EXアビリティ(kind 1-4)

アカウント共通のプール。この取得アカウントでは**全60種**。各ジョブの候補数は58〜60で、自ジョブの基本アビリティ相当分などが数個除外される。1ジョブ分の候補一覧を取れば全EXアビリティが把握できる。

#### リミットアビリティ(kind 5): 同系列の和集合

候補 = **同系列(`job_id`接頭2桁が共通)の特定クラスのリミットアビリティの和集合**。継承範囲はジョブ種別で決まる(全77ジョブで確認):

| ジョブ種別 | リミットアビリティ候補(同系列) |
| --- | --- |
| **ClassI / II / III / V** | ClassIII + ClassIV + ClassV の各`limit_ability`(**ClassIVの極致の証由来は含まない**) |
| **ClassIV(標準系列 10〜19)** | ClassIII + ClassIV + ClassV + **自身の極致の証**(3個) |
| **ClassIV(単独系列: グラディエーター系30・単独ClassIV 41〜47)** | (存在すれば)ClassIII + ClassIV + **自身の極致の証** |
| **オリジン** | ClassIII + ClassIV + **ClassIVの極致の証** + そのオリジン自身 (**ClassV は含まない**) |
| **エクストラ(Ex1)** | 自身(1個) + 対になるEx2(3個)。対のEx2が無いメカニックは自身のみ |
| **エクストラII(Ex2)** | 自身(3個) + **自身の極致の証**(3個) + 対になるEx1(1個) |

- **ClassI/II/III/V は同系列なら候補セットが完全に同一**(例: 剣/斧系列の ウォーリア〈II〉・ウェポンマスター〈III〉・ヴァイキング〈V〉 はいずれも「ウェポンマスター2 + ベルセルク4 + ヴァイキング3 = 9個」)。ClassIVとオリジンだけが極致の証を上乗せする。
- 例: ナイト(剣/槍、11)→ ホーリーセイバー2 + スパルタ3 + パラディン3 = 8個。
- 例: ファイター・オリジン(剣/斧、10)→ ウェポンマスター2 + ベルセルク4 + ベルセルクの極致3 + 自身3 = 12個(ヴァイキング〈V〉のリミットアビリティは含まない)。
- **従来の誤りを訂正**: 「ナイト(ClassI)の自由選択枠はEXアビリティでしか埋められない」は誤り。ClassIも同系列上位のリミットアビリティを`max_zenith`=2個までセット可能。「レスラー(ClassIV)がオーガ(ClassIII)のリミットアビリティを使える」もこの系列和集合の一例(下位→上位の一方向ではなく、系列全体で共有)。

#### ベースアビリティ(kind 6): エクストラIIジョブ限定

**ベースアビリティ候補を持つのはエクストラII(Ex2)ジョブのみ**。中身は対になるEx1ジョブの基本アビリティ。全10種:

| Ex2ジョブ | ベースアビリティ(Ex1由来) |
| --- | --- |
| トーメンター | ダブルアサシン(アサシン) |
| ザ・グローリー | 剣神共鳴 / 集気(剣聖) |
| ソルジャー | トライン / バレットリロード(ガンスリンガー) |
| 黒猫道士 | 宿命陣(賢者) |
| ライジングフォース | 闘志の残響 / 熱烈峻厳(ドラムマスター) |
| マスカレード | プリンシパル・クラシック / リンガリング・セント(ダンサー) |
| ドクター / 魔法戦士 / 剣豪 | 候補0(対になるEx1の基本アビリティがベースアビリティ化の対象外。理由は要確認) |

ClassI〜V・オリジンはベースアビリティ候補ゼロ(`max_base`=2だが該当なし)。ClassI〜III/V が同系列下位ジョブの**基本アビリティ**を使えるわけではない(使えるのはあくまでリミットアビリティ=kind 5)。

**カバレッジ**: 取得可能な全77ジョブ。ClassI版ファイター/ランサー/ウィザードは進化済みで取得不可だが、ClassIルール(同系列ClassIII+IV+V)で候補を導出可能。

## 具体例

- **ClassI(全10ジョブ確認: ナイト/プリースト/シーフ/エンハンサー/グラップラー/レンジャー/ハーピスト/ファイター/ランサー/ウィザード)**: いずれも基本アビリティ2枠+`limit_ability`は0(2026-09-06に7ジョブ、2026-09-07に残る3ジョブ〈ファイター/ランサー/ウィザード〉を確認。ClassIはリミットアビリティを持つジョブが1つも無いクラス)。
- **ClassII(10ジョブ全て確認: ウォーリア/フォートレス/クレリック/ソーサラー/レイダー/アルカナソード/クンフー/マークスマン/ミンストレル/ドラグーン)**: いずれも基本アビリティ3枠+`limit_ability`は0(2026-09-06)。
- **ClassIII(全11ジョブ確認: ウェポンマスター/オーガ/グラディエーター/サイドワインダー/スーパースター/ダークフェンサー/ハーミット/ビショップ/ホークアイ/ホーリーセイバー/ヴァルキュリア)**: いずれも基本アビリティ3枠+リミットアビリティ2枠で一律(ウェポンマスターの例: ブレイブソウル/パワーレイズ、いずれも`level`が空欄=習得Lv不明)。自由選択枠は1つだが選択肢自体は常に複数存在する(2026-09-06)。
- **オリジン(ウィザード・オリジン、ランサー・オリジン)**: ファイター・オリジンと同型 — 基本アビリティ1枠+リミットアビリティ3つ。いずれも進化元ジョブ(ウィザード/ランサー)の`base_job_master_bonus`が非空で別枠加算されることを確認(2026-09-06)。
- **ファイター・オリジン**(オリジンクラス、最大4枠): 基本アビリティ1枠(ウェポンバーストIV) + 自由選択枠3枠(実例ではチャージ・コンバージョン/ドーンブレイク/アンリミテッド・ブーストの3リミットアビリティを選択、EXアビリティは0)。
