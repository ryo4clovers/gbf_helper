# ダメージ減衰（ソフトキャップ）

> ステータス: 下書き
> 最終更新: 2026-09-14
> 出典: [神ゲー攻略「ダメージ上限（減衰）の仕様と上限UPの種類」](https://kamigame.jp/%E3%82%B0%E3%83%A9%E3%83%96%E3%83%AB/%E3%82%B2%E3%83%BC%E3%83%A0%E7%9F%A5%E8%AD%98/%E3%83%80%E3%83%A1%E3%83%BC%E3%82%B8%E6%B8%9B%E8%A1%B0.html)（2025-02-20更新、2026-09-14参照）、[かなたあああ「アビダメ減衰表の作り方（備忘録）」](https://note.com/kanataaaagbf/n/nb9cf64f9a747)（2023-12-29、2026-09-14参照）、[きくまろGaming「ダメージ減衰値一覧」](https://kikumarogaming.com/granbluefantasy-damegecaplist/)（2026-09-14参照）。すべて二次情報であり、数値は実機要検証。

## 概要

グラブルのダメージは、減衰前ダメージが一定のラインを越えるたびに、その超過分だけが小さい割合で通過する。単一の上限で切り捨てる仕組みではなく、複数区間からなるソフトキャップである。通常攻撃・奥義・チェインバーストには代表的な標準表があり、ダメージアビリティは原則としてアビリティ単位で倍率・ヒット数・減衰ライン・通過率を持つ。

## 詳細

### 用語

- **減衰前ダメージ**: 攻撃枠、属性、敵防御、攻撃固有倍率、乱数などを適用し、減衰処理へ渡す値。
- **減衰ライン**: 超過分の伸びが変わる減衰前ダメージの境界。
- **通過率**: 境界を越えた超過分のうち、実ダメージへ残る割合。本リポジトリでは資料の「95%減衰」を`passRate: 0.05`と表現する。
- **ダメージ上限UP**: 最終ダメージへ直接乗算するのではなく、各減衰ラインを同じ割合だけ引き上げる効果として扱う。

### 暫定標準表

| 種別 | 第1ライン / 通過率 | 第2ライン / 通過率 | 第3ライン / 通過率 | 第4ライン / 通過率 | 第4ライン到達時 |
| --- | --- | --- | --- | --- | --- |
| 通常攻撃・反撃 | 300,000 / 80% | 400,000 / 60% | 500,000 / 5% | 600,000 / 1% | 445,000 |
| 奥義・特大（標準） | 1,500,000 / 60% | 1,700,000 / 30% | 1,800,000 / 5% | 2,500,000 / 1% | 1,685,000 |
| 2チェイン | 1,000,000 / 60% | 1,200,000 / 30% | 1,300,000 / 5% | 1,500,000 / 1% | 1,160,000 |
| 3チェイン | 1,250,000 / 60% | 1,450,000 / 30% | 1,500,000 / 5% | 2,000,000 / 1% | 1,410,000 |
| 4チェイン | 1,500,000 / 60% | 1,700,000 / 30% | 1,800,000 / 5% | 2,500,000 / 1% | 1,685,000 |

通常攻撃の例では、減衰前70万を次の区間へ分ける。

```text
300,000 × 100% = 300,000
100,000 ×  80% =  80,000
100,000 ×  60% =  60,000
100,000 ×   5% =   5,000
100,000 ×   1% =   1,000
合計               446,000
```

ダメージ上限10%UPなら、通常攻撃の4ラインは330,000 / 440,000 / 550,000 / 660,000へ移動する。同じ減衰前70万の補正後値は489,900となる。

### ダメージアビリティ

ダメージアビリティには共通の単一減衰表を置かず、次の情報を個別に保持する。

- 基礎倍率（固定値または最小・最大）
- ヒット数（多段は1hitごとに減衰）
- 第1〜第4ライン（4本以外も表現可能にする）
- 各ライン通過後の通過率
- 条件による倍率・ヒット数・減衰表の変化
- 出典、検証状態、確認日

検証時は、減衰へ届かない編成で倍率を先に確定し、攻撃力を段階的に上げて計算値との差が生じる境界を探す。上限UPが含まれる場合、観測した境界を`1 + 上限UP率`で割って基礎ラインを逆算する。与ダメージ上昇などの減衰後効果は外すか、逆算時に後段から除去する。

### 計算機での処理境界

`mcp-server/src/calculator/damageAttenuationCalculator.ts`は、減衰前ダメージと任意個数のラインを受け取る純粋関数として実装した。各区間の入力、通過率、出力を診断情報として返す。固定与ダメージ上昇・割合与ダメージUP・追撃・特殊上限はこの関数へ含めず、後続の独立ステージで扱う。

通常攻撃本体は`乱数 → 多段階減衰 → 与ダメージUP等の後段割合 → 最終整数丸め`の順で計算する。`damage-cap`と`normal-attack-damage-cap`の有効な補正は合算して全減衰ラインを伸長する。通常攻撃の暫定標準表は通常攻撃本体へ接続済み。クリティカル時、追撃、特殊上限の減衰処理は未接続のため別途警告を保持する。

### アビリティ用プロファイル形式

`mcp-server/src/calculator/abilityDamageProfile.ts`に、JSON化できる`schemaVersion: 1`形式を定義した。倍率は固定値も範囲も`multiplier.min/max`で表し、多段アビリティは`hitCount`を保持する。減衰表が未確認のときは推測値を埋めず`attenuation.status: unresolved`、途中のラインまで確認できた場合は`partial`、全ライン確認後は`resolved`として個別の多段階プロファイルを設定する。

```json
{
  "schemaVersion": 1,
  "abilityId": "2040",
  "name": "ドライブバースト",
  "element": "own",
  "targeting": "single",
  "variants": [
    {
      "id": "overdrive",
      "condition": { "type": "enemy-mode", "mode": "overdrive" },
      "multiplier": { "min": 3, "max": 3 },
      "hitCount": 1,
      "attenuation": { "status": "unresolved" },
      "verificationStatus": "下書き",
      "source": "secondary-source-and-user-observation"
    },
    {
      "id": "normal-mode",
      "condition": { "type": "enemy-mode", "mode": "normal" },
      "multiplier": { "min": 1.84, "max": 1.84 },
      "hitCount": 1,
      "attenuation": { "status": "unresolved" },
      "verificationStatus": "検証済み",
      "source": "in-game-observations-2026-09-14",
      "confirmedAt": "2026-09-14"
    },
    {
      "id": "non-normal-fallback",
      "condition": { "type": "always" },
      "multiplier": { "min": 1.84, "max": 1.84 },
      "hitCount": 1,
      "attenuation": { "status": "unresolved" },
      "verificationStatus": "下書き",
      "source": "normal-mode-observation-extrapolation"
    }
  ]
}
```

条件付きvariantを先、必須の`always`フォールバックを最後に置く。現時点の条件は敵モード（通常・OD・ブレイク）、コンパニオンウェポン装備有無、複数条件のANDを表現できる。これによりディストリームの通常5hit／コンパニオンウェポン時10hitも同じ形式で保持できる。検証済みvariantには`confirmedAt: YYYY-MM-DD`を必須とし、倍率・hit数・減衰表の確度をアビリティ単位で混同しない。

## 具体例

コロッサスボンバー・イラ検証で使用したファイア、ドライブバースト、ディストリームは減衰前の倍率・技錬固定加算を確認できたが、各アビリティの減衰ラインは未確認。技錬の固定加算が減衰後に入るため、減衰表の検証では技錬武器を外した状態を基準とする。

同じ検証編成で取得した主人公通常攻撃21hit（21,103〜22,852）は、`ceil(20,513.64161496 × 乱数 × 1.066)`へ0.001刻みの乱数0.965〜1.045を当てると21/21件一致した。最大試行は減衰前21,436.755、後段割合6.6%適用後22,852まで線形計算と一致したため、この範囲までは通常攻撃の減衰なしと実機確認済み。ただし、暫定標準表の第1ライン300,000には大きく届かず、ライン値と通過率の検証根拠にはならない。

ドライブバースト（action ID `2040`）の通常モードを、アビ上限UP・固定与ダメージ上昇なしの編成で11回検証した。通常攻撃21hitがすべて既存式と0.001刻み乱数で一致する共通基礎値20,513.64161496を基準にすると、`ceil(基礎値 × 1.84 × 乱数 × 1.036)`でアビリティ11hitすべてを再現した。対応乱数は0.961〜1.034。よって通常モード倍率1.84倍を検証済みとする。最大試行は減衰前39,028.434、後段与ダメージ3.6%適用後40,434で線形式と一致したため、この範囲までは減衰なし。最初の減衰ラインは未到達である。

イクサバを1本追加した編成②では、通常攻撃11hit（32,029〜34,459）とドライブバースト11hit（58,406〜62,395）を追加検証した。両系列は共通の減衰前基礎値`31,232.303超〜31,232.308以下`と0.001刻み乱数で全件同時に再現できる。最大試行の減衰前ダメージは通常攻撃が約32,325.44、ドライブバーストが約60,225.88であり、いずれも線形式と一致した。これにより減衰なしを確認できる下限を更新したが、通常攻撃の暫定第1ライン300,000は未検証のままである。

コロッサスケーン・マグナを1本追加した編成③では、通常攻撃13hit（52,708〜56,130）とドライブバースト13hit（94,549〜102,740）を追加検証した。両系列は共通の減衰前基礎値`51,773.721超〜51,773.827以下`と0.001刻み乱数で全件同時に再現できる。最大試行の減衰前ダメージは通常攻撃が約52,653.93、ドライブバーストが約99,169.56であり、いずれも線形式と一致した。通常攻撃の暫定第1ライン300,000は引き続き未検証である。

ニーラカンタを1本追加した編成④では、通常攻撃15hit（82,379〜89,899）は減衰前約84,332.88まで線形式と一致した。一方、ドライブバースト15hit（136,686〜145,868）では線形式からの圧縮を検出した。第1ライン117,000まで100%、その超過分を60%通過、後段割合3.6%の順で計算すると、減衰前約141,893〜156,665の15hitを0.001刻み乱数で全件再現できる。第1ラインと通過率は実機検証済み。第2ライン以降は未到達のため、プロファイルは`partial`として保持する。
