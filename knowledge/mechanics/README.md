# ゲームシステム ナレッジ 目次

グランブルーファンタジーの基本的なゲームシステム・仕様をまとめるカテゴリ。
キャラクターや武器などの個別データではなく、「仕組み」「ルール」「計算式」を扱う。

## ステータス凡例

- 未着手: ファイルとタイトルのみ作成済み
- 下書き: 内容を記入中(未検証)
- 検証済み: 公式情報等で内容を確認済み

## 運用ルール

- 1トピック = 1ファイルを基本とする。肥大化したら分割する。
- 各ファイルは下記のテンプレート形式に沿う(`_template.md`参照)。
- 数値やバランス調整に関わる内容は、公式発表や検証済みの一次情報を元に記載し、
  出典または確認日を明記する。不確かな情報は「要検証」と明記してから記載する。
