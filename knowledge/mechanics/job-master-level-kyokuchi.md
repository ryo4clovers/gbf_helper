# ジョブのマスターレベル・極致の証

> ステータス: 下書き
> 最終更新: 2026-09-06
> 出典: ゲーム内HELP(実機、`draft/ゲーム内HELP/プレイヤー.json`、ユーザー提供、2026-09-06)の「プレイヤー」カテゴリ内トピック(id=8「マスターレベル」、id=10「極致の証」、および関連する id=2/12/16/18/19/21/24/25/26/28/38/40/42)。GameWith/gbf.wikiでのクロスチェックは未実施。

## 概要

**マスターレベル**と**極致の証**は、いずれも**Class.IVおよびEX II(エクストラII)ジョブにのみ存在する**追加強化システム。通常のジョブLv(上限20)を上げきった後、さらにそのジョブを強化していくための仕組みで、マスターレベル→極致の証の順に段階的に解放される(極致の証はマスターレベルの上位に位置づけられる強化)。ClassI〜III・V・Ex1・オリジンには存在しない。

具体的な強化量・EXP必要量・トレジャー消費量などの数値データは未取得(ユーザーより「強化データが入っているであろうJSON」を別途提供予定とのこと)。本ファイルは、ゲーム内HELPで確認できた**仕組み・ルールの整理**が中心。

## 詳細

### マスターレベル

- **対象**: Class.IVおよびEX IIジョブのみ。
- **解放条件**: 対象ジョブのジョブLvを20まで上げ、かつ「特定の条件」を満たすこと(条件の具体的な内容はHELP文面には無く未確認)。
- **効果**: EXPを獲得してマスターレベルを上昇させることで、そのジョブをさらに強化できる。具体的には(id=16「アビリティの習得と強化」より):
  - 新たな**サポートアビリティ**を習得する。
  - **ジョブ固有のアビリティ**(基本アビリティ)が強化される。
  - これは実際に[class4-wrestler.md](../jobs/class4-wrestler.md)等で確認済みの「マスターレベル20でストロングスタイル習得」「マスターレベル30でアビリティ1が強化(＋化)」という記載と整合する。
- **マスターレベルの上限は30(確定、2026-09-06)**。実機の`job_master_level`相当のレスポンス(ベルセルクの実例、ユーザー提供)で確認。
- **レベル別強化の型(ベルセルクの実例から判明、2026-09-06)**: Lv2〜30の各レベルごとに1件ずつボーナスが付与される(Lv1にはボーナス無し)。ベルセルクの場合、「攻撃力+300」「HP+300」「ダメージ上限+1%」の3種類がほぼ交互に繰り返され、Lv20で新規サポートアビリティを1つ習得、Lv30でジョブ固有アビリティ(基本アビリティの1つ)が「＋」に強化される、という型。**この「Lv20でサポート新規習得、Lv30でアビリティ強化」という配置がジョブ共通のパターンかどうかは他ジョブのデータが揃うまで未確定**(現状はベルセルク1件のみ)。
- EXPカーブ(各マスターレベルに必要なEXP量)はこのレスポンスには含まれておらず未取得。

### 極致の証

- **対象**: マスターレベルと同じくClass.IVおよびEX IIジョブのみ。
- **解放条件**: **10種類以上の**Class.IV/EX IIジョブのマスターレベルをLv30以上に強化し、かつ「特定の条件」を満たすこと。**個々のジョブの条件ではなく、プレイヤーが育てたジョブの本数に依存する解放条件**である点に注意(1つのジョブだけをひたすら育てても解放されない)。
- **効果**: 「トレジャー」(アイテム)を消費して「練度」を上げることで、そのジョブをさらに強化する。
  - 最大段階は**6段階**。
  - 6段階まで強化すると、そのジョブのアイコンに「コンプリートマーク」が追加される(実績・見た目の変化)。
  - 強化内容は「ステータス強化」と「追加リミットアビリティの習得」の2系統がある([class4-wrestler.md](../jobs/class4-wrestler.md)の極致の証セクションで確認済みの実例: 1〜6段階でステータス強化(攻撃力/HP/弱体成功率/奥義ダメ/CBダメ/奥義ダメ上限)＋3つの追加リミットアビリティ)。
  - **追加リミットアビリティの習得は極致の証を最大まで強化した時**(id=18「リミットアビリティの習得」より)。特定のトレジャーを消費して習得する。
- **極致の証由来のリミットアビリティのセット制限**(id=18・id=24より): 習得したジョブ本人、および**同系統のOrigin Classジョブ**でのみセット可能。他のジョブ(通常のClass.IV他ジョブ、Class.III/V等)ではセットできない。

### Origin Classジョブとの関係(重要な追加確認事項)

id=24「Origin Classジョブ」より、これまでの[abilities.md](./abilities.md)の記載を補強・一部修正する情報が得られた:

- **Origin ClassジョブはClass.Iジョブから進化する**(進化すると進化元のClass.Iジョブ自体は使用できなくなる)。
- **進化条件**: 全てのClass.VジョブのジョブLvを20まで上げることで発生するフリークエストをクリアした後、特定の条件を満たした上でJPを消費してClass.Iジョブから進化する。
- Origin Classジョブは「上限解放」を行うことができる(id=25、対象ジョブの一部が上限解放でジョブLv上限を伸ばせる仕組みと同種と思われる)。
- **Origin Classジョブがセットできるリミットアビリティの範囲(重要)**:
  - 同系統のClass.IIIジョブのリミットアビリティ
  - 同系統のClass.IVジョブのリミットアビリティ(**極致の証で習得したものも含む**)
  - 同系統のClass.Vジョブのリミットアビリティは**セット不可**
  - Origin Classジョブ自身のリミットアビリティは、他のジョブではセットできない

  これは、[abilities.md](./abilities.md)で確認済みの「レスラー(ClassIV)がオーガ(ClassIII、同系統)のリミットアビリティを自由選択枠で使える」という実例と整合する仕組みで、**Originはさらにその範囲がClassIII+ClassIVの2階層に及ぶ**ことを示している。ClassVのリミットアビリティだけが対象外という非対称ルールは要記憶。

### Class.II〜Vのアビリティ枠の違い(id=12「上位ジョブ」より、既存abilities.mdとの整合確認)

- **Class.II・Class.IIIジョブ**: アビリティ自体がより強力、特殊条件下で絶大な効果を発揮するものがある(枠構成はClass.Iと同様、基本アビリティ主体+自由選択枠1)。
- **Class.IV・Class.Vジョブ**: 「アビリティをひとつしか習得しない代わりに、『Freeアビリティ』と呼ばれる枠に**EX・リミットアビリティをそれぞれ2つ、計3つまで**セットすることができます」。

  **食い違いは解消(2026-09-06、ユーザー確認)**: 実機のアビリティ選択UIには、Class.IV/Vも含めて全クラス共通で「ベースアビリティ」の絞り込み(フィルタ)自体は存在する。ただし**ベースアビリティを持つジョブ(＝同系統に下位のEx1相当ジョブがあるジョブ)の方が少数派**で、大半のジョブでは絞り込んでも候補が0件になる。HELP文面(id=12)がClass.IV/Vの説明でベースアビリティに触れていないのは、UIとして存在しないからではなく、**候補が無いケースが大半のため説明を割愛した**(EX IIの説明(id=19)では逆に候補が実在するケースが多いため明記された)という理解で整合する。

### 用語の整理(id=38/42/28/45より)

- **アビリティ**: プレイヤーやキャラクターがバトル中に使う、通常攻撃以外の技全般の総称。プレイヤーはジョブLv上昇で、他キャラクターは特定クエストクリアで新たに習得する。
- **EXアビリティ**: 「プレイヤーの一部のアビリティは『EXアビリティ』として、他のジョブでもひとつだけ使用することができます」。文面上、1つのEXアビリティを**同時に使える他ジョブの数が1つまで**なのか、**プレイヤーが自由選択枠にセットできるEXアビリティの数が1つまで**なのか、解釈がやや曖昧(前者だと考えられるが要検証。後者だとすればClass.IV/V/EX IIの「EX上限2」という既存記載と矛盾するため、後者ではないと考えられる)。
- **サポートアビリティ**: 戦闘中常時発動する能力(攻撃力/防御力等のステータス上昇系が中心)。
- **リミットアビリティ**: 特定条件を満たし「LB」または「ジェム」を消費して習得する「ジョブ専用EXアビリティ」。習得すると対応ジョブでのみ使用可能。
- **ジョブLvとコンプリートボーナス**(id=26): 通常のジョブLv上昇で得る「Lvアップボーナス」と、ジョブLv最大到達で得る「コンプリートボーナス」(ジョブを変更しても効果が継続する)は別物。マスターレベル/極致の証はこれらとも別の、さらに上位の強化階層。
- **能力強化/能力リセット**(id=21/40): 「Limit Bonus Class」で定められた回数まで、任意の能力を選んで強化できる仕組み(LBまたはジェムを使用)。リセット可能だが、リセットしても消費したLB/ジェムは返還されない。習得済みのリミットアビリティ自体はリセット不可。マスターレベル/極致の証と同じ「LB/ジェム/トレジャーを消費する強化」の枠組みに属するが、対象が異なる別システムと思われる(要整理)。

- [class4-wrestler.md](../jobs/class4-wrestler.md)「マスターレベル強化」「極致の証」セクション(GameWith記事ベース、数値の粒度は粗い): マスターレベル20でサポートアビリティ「ストロングスタイル」習得、マスターレベル30でアビリティ1が強化、極致の証1〜6段階でステータス強化+3つの追加リミットアビリティ「タッグチーム」「ファイティングソング」「ヒール・タイム」を段階的に習得。
- [class4-berserker.md](../jobs/class4-berserker.md)「マスターレベル強化」セクション(実機`job_master_level`レスポンスベース、2026-09-06、レベル別の精密な内訳): マスターレベル2〜30の29段階、うち26段階が「攻撃力+300」「HP+300」「ダメージ上限+1%」のいずれかのステータス加算(合計: 攻撃力+3600、HP+1500、ダメージ上限+10%)、Lv20でサポートアビリティ「トランプル」新規習得、Lv30で基本アビリティ「ウェポンバーストIII」が「＋」に強化。**現状唯一のレベル別精密データ**であり、他ジョブでも同じ「Lv20=サポート新規、Lv30=アビリティ強化」の型になるかは要検証。

### マスターレベルのデータ構造(実機レスポンス、2026-09-06判明)

ゲーム画面のマスターレベル詳細ポップアップ(`job_master_level.css`を使う画面)から取得できるデータの構造:

```
{
  data: "<div>...</div>",  // URLエンコードされたHTML断片。ジョブ画像
                            // (leader/master_level/{job_id}_*.png)等を含むが、
                            // 数値データそのものはoption側にある。
  option: {
    job_master_level_bonus: {
      "<マスターLv>": [
        {
          is_master: true,
          master_level: <数値>,
          name: "攻撃力" | "HP" | "ダメージ上限" | "サポートアビリティ習得" | "アビリティ強化" | ...,
          value: "<数値文字列、ステータス系のみ>",
          disp_param: "+300" | "+1%" | "",  // 画面表示用の整形済み文字列
          ability: {...} | [],       // kind="アビリティ強化"の時、強化後のアビリティ情報(job Lv詳細と同形式、class_name/comment/recast等含む)
          support_ability_list: [{...}] | [],  // kind="サポートアビリティ習得"の時、新規習得するサポートアビリティ情報
          image: "bonus_1" | "bonus_14" | "bonus_23" | "bonus_24" | ...,  // ボーナス種別アイコン
          ...
        }
      ]
    }
  }
}
```

`job_master_level_bonus`は**Lv2から始まり**(Lv1にはボーナスが無いためキーが存在しない)、各レベル1件ずつの配列。`ability`/`support_ability_list`は、[knowledge/jobs/](../jobs/README.md)の各ファイルで使っているジョブLv詳細レスポンスの`level_up_bonus`と同じ形式(`class_name`でアイコンURLも組み立てられる)。**HTML断片内の`<script id="tpl-pop-bonus-effect">`テンプレートには、実は該当ジョブの合計値がサーバー側で埋め込まれた状態で入っている**(ベルセルクの例で「+3600」「+1500」「+10%」という値が、Lv2〜30の内訳を積算した実際の合計と完全一致することを確認済み)。これは他ジョブのデータを処理する際の検算に使える。
