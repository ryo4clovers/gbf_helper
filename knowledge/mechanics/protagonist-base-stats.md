# 主人公の基礎ステータス(Rank別HP・攻撃力)とステータス計算式

> ステータス: 下書き
> 最終更新: 2026-09-06
> 出典: ユーザー提供のジョブDB(Googleスプレッドシート「グラブルDBシート_v0.0.0」、@games_ryo名義、以前ダメージ計算機アプリ用に作りかけていたもの)の「主人公基礎ステ」シート(2026-09-06、ユーザーがシート内容を直接貼り付けて提供)。**シート内でも「Rank上昇に伴う主人公基礎HP・攻撃力データ」という位置づけで、公式発表の数値そのものではなく推測・検証ベースの値**である点に注意。計算式は[攻撃力・HPの計算式について - resoleil's blog](https://resoleil.hatenablog.com/entry/2020/07/06/001524)(2026-09-06参照、こちらも非公式の検証結果)。

## 概要

主人公(グラン/ジータ)のRank(ランク)ごとに増える「基礎HP」「基礎攻撃力」の一覧と、それらを元に画面表示される最終的な攻撃力・HPを算出する計算式をまとめる。ジョブ側の数値(ジョブLvアップボーナス・マスターレベル強化・極致の証、[knowledge/jobs/](../jobs/README.md)に個別記載)は、この基礎値に加算される一要素という位置づけ。

## 詳細

### 表示攻撃力の計算式

```
攻撃力 = [
    基礎攻撃力(Rank別、下記表)
  + 攻撃力LB
  + (ジョブLvアップボーナス + Master Level + 極致の証)
  + { 指輪 + 覚醒 + (プラス × 3) }
  + 武器総合攻撃力
  + 武器攻撃力 × { 得意武器1(0.2) + 得意武器2(0.2) + 得意武器LB + メイン武器攻撃力コンプリートボーナス(0.03 or 0.06) }
  + 武器攻撃力 × コスモス補正(0.3 or 0.5)
  + 召喚石総合攻撃力
] × { 1 + コンプリートボーナス(0.19) }
```

- 各乗算のたびに四捨五入が入る(掛け算1回ごとに端数処理、というより「乗算ステップの都度四捨五入」という報告)。
- 得意武器補正(0.2 × 2種)は**主人公も計算対象**(キャラクターと同様)。

### 表示HPの計算式

```
HP = [
    基礎HP(Rank別、下記表)
  + (HPLB + 全体HPLB)
  + (ジョブLvアップボーナス + Master Level + 極致の証)
  + (指輪 + 覚醒 + プラス)
  + 武器総合HP
  + 武器HP × { 得意武器1(0.2) + 得意武器2(0.2) }
  + 武器HP × コスモス補正(0.3 or 0.5)
  + 召喚石総合HP
] × { 1 + コンプリートボーナス(0.15) }
```

- 攻撃力と同様、乗算のたびに四捨五入。
- **キャラクターの場合はHP計算に得意武器補正を含めない**という違いがある(主人公のみ攻撃力・HP両方に得意武器補正がかかる)、との報告。要検証。

## 未確認・要検証事項

- **本ファイルのRank別基礎HP/基礎攻撃力の表は、ユーザーが以前作りかけていた個人用データベース(Googleスプレッドシート)からの転記であり、ユーザー自身「推測値」と位置づけている。公式発表の数値ではなく、実機での裏取りはまだ行っていない。**
- 計算式(resoleil's blogより)も非公式の検証結果であり、公式による裏付けは無い。将来的に実機での数値照合による検証が必要。
- コスモス補正・メイン武器攻撃力コンプリートボーナスの「0.03 or 0.06」「0.3 or 0.5」がどの条件で切り替わるかの詳細は未確認(武器の種類・段階によって変わると推測されるが要検証)。
- キャラクターの表示攻撃力・HP計算式が主人公と完全に同一かどうかは未検証(HPへの得意武器補正の有無に差がある可能性が示唆されている)。
- Rank425より先(Rank426以降)のデータは未収集。
