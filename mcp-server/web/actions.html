戦闘画面編成・計算

奥義OFF・手動アビリティなし

編成から行動をまとめて生成する検証用画面です。通常は編成を選んで戦闘画面の「攻撃」で進めます。対応するジョブ・武器・キャラ・召喚石の効果を個別に適用します。前衛はLv80以上の闇シンダラ・サリエル・浴衣イルザに対応し、人数・並び順を変更できます。自動アビリティのダメージは実測未一致の候補値です。

実効DA・TA率を指定する（抽選時は必須）

武器・神伝の槍手Lv・覚醒・大事なもの等を含めた実効率を入力してください。開幕4ターンの値はオーバースキル等を含める場合の置換値です。空欄なら通常の値を使います。神伝Lvによる率の変化は自動計算しません。

自動アビリティのダメージ計算（下書き）

敵・加護・大事なもの・固定HPの条件を確認してください。HPは全ターン同じ、クリティカルは不発として計算します。編成画面の設定があれば敵・加護・大事なものを引き継ぎます。主人公のジョブLv補正とLBは自動加算し、全体コンプリート等の追加補正は単発APIで個別に指定してください。

ランダム強化のアーティファクト装備者は、該当キャラに artifactStartBuffs: {"attackUp": true/false, "damageCapUp": true/false} を指定します。抽選結果は自動では決めません。

率が未指定の最低・最大連撃は、既知の確定連撃を含む比較用シナリオです。実戦の確率や総ダメージの上下限を示すものではありません。全員生存・全攻撃命中・弱体成功を仮定します。

生成された行動

通常攻撃のhit数は分割後の本体と武器追撃です。自動アビリティのダメージは1hitと1発動の範囲を表示し、未計算の場合はその旨を表示します。
